## 💰 費用の総覧

Lasso 本体は **完全無料・MIT オープンソース** です。各機能の実際のコストは以下の通り：

| 機能 | 費用 | 備考 |
|---|---|---|
| Lasso 本体（MCP サーバー + すべてのコア機能） | ✅ 無料 | MIT オープンソース、永久無料 |
| 検索（Zhipu + Brave + Bing） | ✅ 無料枠あり | Zhipu はトークン課金、Brave は **月 2,000 件無料**、Bing は **月 1,000 件無料**——払わなくても使えます。**マシンに Zhipu の `web-search-prime` MCP を設定済み？ Lasso が自動検出して再利用——ZHIPU_API_KEY を別途設定する必要はありません** |
| 公開ページのスクレイプ / スクリーンショット / PDF / ネットワーク監査 / 生バイト取得 | ✅ 無料 | ローカルで動作、キー不要、支払い不要 |
| ログイン済みページのスクレイプ（ローカル Chrome 再利用） | ✅ 無料 | ローカルで動作、キー不要、支払い不要 |
| デスクトップ操作（macOS / Windows / Linux） | ✅ 無料 | ローカルでビルド・実行、OS の認可だけが必要。署名付きの永続認可には Apple Developer アカウント \$99/年が **任意**（未署名でも動作——その都度再認可するだけ） |
| クラウドブラウザ · セルフホスト Steel（v1.6 新） | ✅ 無料 | ローカル Docker で Steel（Apache-2.0 オープンソース）を運用——**セッション単位の費用ゼロ + cookie はローカルから出ない**；`LASSO_ALLOW_CLOUD_BROWSER=true` + `STEEL_ENDPOINT=http://localhost:3000` が必要 |
| クラウドブラウザ · ホスト型（browserbase / stagehand） | ⚠️ 有料・デフォルトはオフ | browserbase はトライアル後は従量課金；stagehand はプログラマティックな実験チャンネル（MCP ツール入口なし）；**設定しなければ一切課金されません** |
| `browse_headless` のアンチ検出（v1.5 新） | ✅ 無料 | デフォルトで 16 層のアンチ検出を注入（UA / webdriver / webgl など）——基本的なボット検出の多くをそのまま通過 |

> 一言で言えば：**ホスト型クラウドブラウザ（browserbase / stagehand）を有効にしない限り、Lasso のコストはゼロ** です——検索には日常使いに十分な無料枠があり、セルフホスト Steel も無料です。

## 60秒ではじめる

### 30秒 · 一行インストール（設定ゼロ）

```bash
claude mcp add lasso -- npx -y lasso-mcp
```

Claude Code を再起動 → `/mcp` → `lasso ✓ Connected` と表示されれば完了。**インストールコマンドにキーは一切不要**——設定は別ステップ（次の層）で行います。

### 30秒 · 設定なしでもう既にできること

インストール直後、キーがなくても以下はすべて使えます（**ティア 1：設定ゼロ**）：

- **公開ウェブページ**のテキストを取得し、整った markdown に変換
- **ページ全体のスクリーンショット** と **PDF 保存**（ファイルパスを返す）
- ページが読み込む **サードパーティのトラッカー** を確認
- JSON API やファイルから生バイトを直接取得
- macOS のネイティブアプリを操作（Finder / Mail / システム設定など——システム設定で一度だけチェックが必要）

> 💡 **検索も設定ゼロで使える可能性があります**：マシンの `~/.claude.json` に Zhipu の `web-search-prime` MCP が既に設定されていれば、Lasso は起動時に自動検出して再利用します——`ZHIPU_API_KEY` を別途設定する必要すらなく、検索がそのまま使えます。`lasso doctor` で `#36 machine_search_mcp` が `pass` かどうか確認してください。

最初の一歩——Claude にこう言うだけ：

> 「example.com のテキストを取得して markdown にして」

### もっと欲しい？ 設定ファイルで追加（ティア 2）

- **検索** → `lasso config init` を実行して `~/.lasso/config.json` を作成し、Zhipu のキーを記入（[設定](#設定) を参照）
- **ログイン済みページのスクレイプ**（Jira / プライベート GitHub / 社内ネット） → `lasso launch-chrome` を一度だけ実行
- **macOS デスクトップの操作** → `lasso doctor` を一度だけ実行して認可を案内してもらう

各キーの取得方法や無料枠の詳細は [**キー設定ガイド**](./doc/KEY-GUIDE.md) を参照してください。

## 何ができるか

**ツール名**ではなく、**やりたいこと**ごとに整理しています。どれも一言で入力し、一言で結果が返ります。

### 検索

> あなた：「X を検索して」→ 構造化された検索結果

デフォルトは Zhipu（中国語に強い）。Brave と Bing を追加してマルチソース化も可能。**いずれかのソースがレート制限や障害で使えなくなっても、自動で次に切り替わります——ユーザーは何も感じません。** 一つのプロバイダーの無料枠を使い切っても、全体が止まることはありません。

**ニュースやバージョン動向**のような時間感度の高い内容を調べたいときは、「直近 1 週間 / 直近 1 ヶ月の X を検索して」とそのまま言えば OK——時効フィルタ（day / week / month / year、全エンジン共通——Bing のみ「年」粒度がなく自動スキップ、v1.11）が自動で付き、クエリに日付を手書きする必要はありません。

### 公開ページのスクレイプ（ログイン不要）

> あなた：「example.com のテキストを取得して」→ 整った記事テキスト（3 段階の粒度を選択可能）

ナビバーや広告、サイドバーなどの雑多な要素を自動で除去——**トークンを 30〜70% 節約**（費用も抑える）。GitHub / Reddit / Hacker News / Wikipedia / Substack / Medium など**頻出 20 余りのサイトは専用抽出器**で処理され、表や数式の構造も失われません（v1.12）——本文中のリンクはすべてクリック可能な絶対アドレスになります。引用マーカーが必要（研究や RAG への投入に最適）なら、一言でモードを切り替えられます。

> **v1.5 以降、`browse_headless` はアンチ検出（ステルス）がデフォルトで有効**（UA 偽装 / `navigator.webdriver` 抹消 / webgl・plugins・codecs 偽装など十数層）。**設定不要で自動的に効きます**——「headless を検出する」サイトの多くがそのままスクレイプ可能に（v1.8 で注入が黙って無効になる欠陥を修正、現在は本当に効いており、注入失敗はログに正直に報告されます）。v1.11 からはアンチ検出が**ブラウザ起動レイヤー**で効きます：UA・ビューポート・言語がプロファイルで統一されて適用され、ネットワーク層の HTTP ヘッダーとページ JS が同じ値を見るため、もう矛盾しません。v1.12 からは macOS でデフォルトのフィンガープリントが**あなたのシステムと整合**（「UA は Windows、マシン特性は macOS だと白状」という矛盾を解消）。Cloudflare 級の強力なアンチボットにだけクラウドブラウザが必要です（下記「アンチボット回避」参照）。アンチ検出の効果を確認したい？ `lasso doctor --stealth-check` で creepjs の検出比較を見られます。

### ログイン済みページのスクレイプ（2FA があっても）

> あなた：「自分の Jira の ToDo を見せて」→ ログイン済みページのスナップショット

**ローカルでログイン済みの Chrome** を再利用——2FA は一度だけ自分で通し、あとは Lasso が引き受けます。プライベート GitHub リポジトリ、社内ネット、有料購読コンテンツなどでも機能します。

> 🔴 **レッドライン**：Lasso は **2FA / SMS 認証 / CAPTCHA / マジックリンクを代わりに解除することは絶対にありません**。これらは必ずローカルの Chrome で一度だけ自分で通してください。

### 生バイトの取得（最速・最安）

> あなた：「この JSON エンドポイントを GET して」→ 生バイトデータ

ページ全体をレンダリングする必要がない場合、直接 HTTP で取得する方がブラウザ経由より **約 4 倍速く、約 4 倍安く** すみます。コンテンツタイプ（JSON / テキスト / バイナリ）は自動検出されます。

### スクリーンショット / アーカイブ

> あなた：「ページ全体のスクリーンショットを撮って」／「PDF で保存して」→ ディスク上のファイルパス

画像も PDF も **ディスクに保存され、パスが返されます**——チャットに巨大なデータが流れ込んでコンテキストを無駄遣いすることはありません。超大量のテキスト出力（fetch_url / network など）が 48 KiB を超える場合も自動でディスクに落とされ、プレビュー + `@oN` のページ継続ハンドルが返ります——`read_text` ツールでページごとに続きを読めます（v1.8 から MCP 経由で直接呼び出し可能）。

### ページが読み込むものを可視化

> あなた：「このページが読み込んだサードパーティのトラッカーを教えて」→ トラッカードメインごとの集計付きリソース一覧

ページが読み込むすべてのリソースを自動で識別し、サードパーティドメインごとにグループ化——プライバシーリスクやパフォーマンスのボトルネック発見に重宝します。v1.11 からはリソース収集がブラウザエンジンのネイティブなネットワーク層を直接利用——**プロキシ / TUN ネットワーク環境でも完全**で、各リソースにリクエストメソッドとステータスコードも付きます。

### ネイティブデスクトップアプリの操作

> あなた：「ダークモードをオフにして」／「Mail の受信トレイの一番上のメールを読んで」→ 自動操作（検証付き）

macOS では Finder / Mail / Safari / メモ / システム設定など、すべてのネイティブアプリを操作できます。**Windows と Linux でも動作します**（下記の正直な境界線を参照）。すべての操作は検証され——「本当に実行された」ことを確認し、成功を偽ることはありません。

> **正直な境界線**：macOS は実機で検証済み、Windows / Linux はコンパイル時と契約レベルのセルフチェックを通過していますが、実機での網羅的手動テストはまだ進行中です。**「Win/Linux で完全検証済み」とは偽りません。**

### ウェブとデスクトップをまたぐ統合スケジューリング

> あなた：「今操作できるものをすべてリストアップして」→ 統合された一つのリスト

ウェブページとデスクトップウィンドウが一つのリストを共有——「これはブラウザの中」「これはデスクトップ」と区別する必要はありません。Claude が何を操作すべきかを選び、そこからすべてが流れていきます。

### リンク切れの復元

> あなた：「このリンク 404 だ」→ Internet Archive の最新スナップショット

Internet Archive（Wayback Machine）に飛んで、その URL の最後にアーカイブされたコピーを探します。**生きているリンクを切れたとみなすことは絶対にありません**——「これは消えた」とあなたが言った時だけ探しに行きます。

### アンチボット回避（デフォルトはオフ）

> あなた：「このサイト Cloudflare がいてスクレイプできない」→ クラウド Chrome のアンチボット

**デフォルトでは完全にオフ。** あなたが明示的に有効化し、かつクラウドブラウザ（セルフホスト Steel またはホスト型 browserbase / stagehand）を設定した場合にだけ動作します。軽度のアンチボットは `browse_headless` 内蔵のアンチ検出で通ります——**Cloudflare 級の強固な保護にだけクラウドブラウザが必要**です。

- **Steel セルフホスト（推奨 · 無料）**：ローカル Docker でオープンソースのクラウドブラウザを運用——セッション単位の費用ゼロ、cookie はローカルから出ません。一行のコマンドで開通、[キー設定ガイド · Steel](./doc/KEY-GUIDE.md#steel_endpoint--自托管云浏览器v16-新推荐免费) を参照。
- **browserbase（ホスト型 · 有料）**：トライアル後は従量課金。自分で Docker を運用したくない場合の選択肢。
- **stagehand（ホスト型 · 有料）**：⚠️ プログラマティックな実験チャンネル——キーを設定しても内部チャンネルを組み立てるだけで、**MCP ツールの入口はありません**（REST 契約は未検証；`lasso doctor` #39 `stagehand_rest_contract_probe` がこれを専用チェック）。

## インストール

クエリを拒否**——`where` は text / role のみ受け付け、純 ref クエリは正直に invalid_params を報告（従来は全ツリー一致へ黙って劣化し、トークン爆発のうえ成功を装っていた）；**終了がより速くより安定**——Steel セッション解放に 3 秒の上限を追加（セルフホスト Steel 停止時でも CC の終了が最長 5 分固まらなくなった）；VLM 案で macOS の入力合成権限が欠落している場合、曖昧な失敗ではなく「認可が必要」と明示；v1.12 実装層チューニング 14 件（最適性レビュー第 2 ラウンド）：**markdown 抽出のデュアル活性化**——defuddle のサイト専用抽出器（HN / Reddit / GitHub / Wikipedia / Substack / Medium など 20 余りのサイト）+ 表・数式の構造忠実変換（GFM テーブルが構造を失わない；相対リンクの自動絶対化；出力に `==ハイライト==`、`[^N]` 脚注などの Obsidian 方言が含まれることがある）；**ヘッドレスブラウザのデフォルトフィンガープリントをホストシステムと整合**——macOS ではデフォルトで macOS Chrome フィンガープリント（「UA は Windows、client hints は macOS」という矛盾を解消；doctor はインストール済み Chrome とのバージョン偏差をヒント表示）；**デスクトップチェーン末尾の正直化**——VLM スクリーンショット推定が成功を偽らなくなった（実行できるなら真に実行、できないなら正直に unknown）；`wait/expect` は連続 2 回のヒットが必要（読み込み瞬間の要素で偽成功しない）；`snapshot` は切り詰め時にトップレベルへ `truncated:true`；`find` はヒットノードに実行可能アクション一覧を付与；**Electron 入力欄の修正**——AXSetValue を飲み込むコントロール（Slack / VSCode など）では type が「フォーカス + キーボード合成」（ASCII）へ自動降格；**ドラッグが実用に**——押下 200ms + 12 点補間軌道 + 沈静 100ms（スライダー／ドラッグソートが高確率失敗から実用へ）；**freshness の全経路一貫**——machine_mcp と DuckDuckGo フォールバックが時効パラメータを黙って捨てなくなった；CC 異常終了時に Lasso プロセスが即座に後始末（従来は最長 1 時間の残留）；v1.11「全インタラクション取っ手」の実装次元を補完：**デスクトップが「見える」から「押せる」に**——`desktop` の click / type / scroll が本物に実装（AXAPI 意味的クリック + 書き込み後読み戻し検証 + 期限切れ参照の正直なエラー）。さらに座標マウス操作（ドラッグ／ホイール／移動、canvas / Electron 向けフォールバック）と `skeleton` ツリー刈り込み（高密度アプリでトークン大幅減）を追加；**ドライバ層を chrome-devtools-mcp 0.3.0 → 1.7.0 へ更新**（11 ヶ月 57 リリース分の恩恵；起動レベルのアンチ検出 UA / ビューポート；上流テレメトリはデフォルトで無効化済み）；**search に `freshness` 時効フィルタを追加**（day / week / month / year を全エンジンへ透過——ニュース／バージョン動向の調査でクエリに日付を手書きしなくてよい）；英文クエリのキーなしフォールバックを Baidu から DuckDuckGo へ変更；`LASSO_PROXY` ブラウザアウトバウンドプロキシを追加（ヘッドレス／クラウドブラウザのみに影響——ログイン済み Chrome の出口は不変）；v1.10 ブラウザはデフォルトでサイレント + 使い終わったら閉じる：`launch-chrome` はデフォルトでウィンドウゼロ・ゼロストレス起動（macOS / Windows 対応、`--mode visible` で戻せる）、常にバックグラウンドのアンチスロットリングとミュート付き、サーバー稼働中は最終使用から約 60 秒で自動クローズ（`LASSO_LAUNCH_IDLE_MS` で調整可能。5 分の挙動は 300000 chrome-devtools-mcp@0.3.0 の契約適応、スクリーンショットの実ディスク保存、launch-chrome の生存プローブ、呼び出し元クォータの配線、`read_text` ページ継続ツールなど——完全なリストは [doc/17-功能测试清单.md](doc/17-功能测试清单.md) の「v1.8 修复记录」を参照）。

**前提条件**：Node.js ≥ 20、Claude Code（または MCP 対応の任意のクライアント）。

```bash
# Claude Code（推奨）
claude mcp add lasso -- npx -y lasso-mcp
```

Claude Code を再起動 → `/mcp` → `lasso ✓ Connected`。**これで完了——インストールコマンドにキーは不要です。** ブラウジング / スクリーンショット / PDF / デスクトップ操作は即座に使えます（検索だけが例外——[設定](#設定) を参照）。

**デスクトップ操作を使いたい macOS ユーザー**：`lasso doctor` を一度実行し、案内に従って「システム設定 → プライバシーとセキュリティ」の **アクセシビリティ** と **画面収録** の両方で `lasso-rust-helper` にチェックを入れてください（`doctor` が案内するので、自分でパスを探す必要はありません）。

## 設定

**インストールは設定ゼロ**——上記のインストールコマンドだけで、ブラウジング / 取得 / スクリーンショット / PDF / サードパーティリソースの検査 / デスクトップ操作が有効になります。**キーが必要なのは検索だけです。**

### やりたいことから調べる

| やりたいこと | 設定するもの | 解放される機能 |
|---|---|---|
| 公開ページのスクレイプ / スクリーンショット / PDF / トラッカー確認 / 生バイト取得 / デスクトップ操作 | **何もなし** | インストール直後に動作 |
| 検索 | Zhipu のキー一つ（無料で取得可） | メインの検索エントリー |
| 検索失敗をほぼゼロに（マルチソース化） | Brave / Bing のキーを追加（どちらも無料枠あり） | 一つがダウンしても自動切り替え——ユーザーは何も感じない |
| ログイン済みページのスクレイプ | `lasso launch-chrome` を一度だけ実行 | ローカルの Chrome セッションを再利用 |
| macOS デスクトップの操作 | `lasso doctor` を一度だけ実行 | ネイティブアプリを操作 |
| Cloudflare 保護下のサイトのスクレイプ | 二重確認 + クラウドブラウザチャンネル（セルフホスト Steel は無料 / ホスト型は有料） | デフォルトはオフ——明示的な有効化が必要 |

以下では、4 つのモジュールを「とりあえず動く」までの最短経路で紹介します。

### 1. 検索（✅ 無料 · 無料枠あり；キー一つで起動、3 つでほぼゼロ失敗）

**機能**：あらゆるものを検索し、構造化された結果（タイトル、スニペット、リンク）を返します。

**キーは必要か**：はい——ただし、マシンの `~/.claude.json` に Zhipu の `web-search-prime` MCP が既に設定されている場合（`mcpServers` に type=http + Authorization で記載）、**Lasso は起動時に自動検出してそのキーを第一優先ソースとして再利用します——ZHIPU_API_KEY を別途設定する必要はありません**。マシン MCP がレート制限や失敗に陥ったら、Lasso 自身のキー（下記で設定）へ自動フォールバック。`lasso doctor` で `#36 machine_search_mcp` が `pass`（host=open.bigmodel.cn）か `warn`（未検出）か確認できます。

> 設定ゼロの優先順位：マシン MCP 再利用 → Lasso の `ZHIPU_API_KEY` → Brave → Bing → `browse_headless` フォールバック。前が落ちたら自動で次へ——ユーザーは何も感じません。

**設定方法**（マシンに Zhipu MCP がない / 独立したキーが欲しい場合のみ）：

```bash
lasso config init        # ~/.lasso/config.json のテンプレートを作成
lasso --version          # バージョン番号を確認（v1.8〜）
lasso --help             # 全サブコマンドの使い方を表示
```

> v1.8 からコマンドラインが通常の慣例に準拠：未知のサブコマンド / 未知の引数は使い方を表示して非ゼロで終了し、黙って MCP サーバーモードに落ちて入力を待つことはなくなりました。

`~/.lasso/config.json` を開いて以下を記入：

```json
{
  "ZHIPU_API_KEY": "your_zhipu_key"
}
```

**より堅牢にしたい場合**（強く推奨）：Brave と Bing も追加——どちらも無料枠があります。いずれかのソースがレート制限や障害で使えなくなっても、自動で次に切り替わります：

```json
{
  "ZHIPU_API_KEY": "your_zhipu_key",
  "BRAVE_API_KEYS": "bravekey1,bravekey2,bravekey3",
  "BING_API_KEYS": "bingkey1,bingkey2"
}
```

> 複数キーはカンマ区切り——N 個のキーで無料枠が N 倍に、自動ローテーションされます。

キー名は上の表の記載と一致しています——そのまま記入してください。保存すれば、次回起動時に Lasso が読み込みます。

**キーの取得方法、無料枠の上限、複数キーのローテーションの詳細** → [キー設定ガイド · 検索](./doc/KEY-GUIDE.md#a-搜索) を参照。

### 2. ログイン済みページのスクレイプ（✅ 無料 · キー不要、コマンド一回だけ）

**機能**：ログイン済みのページ——Jira の ToDo、プライベート GitHub リポジトリ、社内ネット、有料購読コンテンツ——をスクレイプします。

**キーは必要か**：いいえ。

**設定方法**：以下のコマンドを一度だけ実行。ローカルの Chrome を自動検出し、デバッグポート付きで起動します。v1.8 からは Lasso 独自の**独立プロファイル**をデフォルトで使用（Chrome 136+ はデフォルトプロファイルでのデバッグポートを禁止しており、旧方式は即終了していました）。このウィンドウで最初に一度アカウントへログイン（2FA は自分で通す）すると、**このプロファイルのログイン状態が以後ずっと再利用**されます：

```bash
lasso launch-chrome
```

起動後、Lasso はデバッグポートを自動でプローブ（`curl /json/version` 相当の検証）：Chrome が起動しない / ポートが塞がっている場合は**明確にエラーを出し**、「成功を返すのに実は繋がらない」ことはなくなりました。既存のプロファイルディレクトリを再利用したい場合は `lasso launch-chrome --profile <ディレクトリ>`。

**v1.10 からデフォルトで「サイレント稼働」**：この Chrome は**ウィンドウゼロで起動、キーボード／ウィンドウフォーカスを奪わず、常にミュート**——あなたが前面でコードを書いている間、背面でページを取得し、互いに干渉しません（唯一感知できる痕跡は Dock / タスクバーに増える Chrome アイコンで、これは OS レベルで除去できません）。動作を見たい場合は `lasso launch-chrome --mode visible`（または `~/.lasso/config.json` に `"LASSO_LAUNCH_MODE": "visible"`）。

その後、Claude に「ログイン済みの Jira を開いて」と言えば自動で繋がります。

> 🔴 **レッドライン**：2FA / SMS 認証 / CAPTCHA / マジックリンク——Lasso はこれらを代わりに解除することは絶対にありません。必ずローカルの Chrome で一度だけ自分で通してください。

**使い終わった後の後片付け（v1.10 からほぼ放置で OK）**：サーバー稼働中、この Chrome は**最後に使われてから約 60 秒で自動的に閉じます**（使い終わったら閉じる——待つ必要も覚えておく必要もなし）。しきい値を調整するには：`LASSO_LAUNCH_IDLE_MS=300000` で 5 分に戻す、`=1000` でほぼ即時（代償として間隔の空いた操作には約 11 秒の再コールドスタート）、`=0` で自動クローズ無効。単発の長時間タスクを実行する場合は `lasso launch-chrome --idle-ms 3600000`。手動で閉じることも常に可能（Lasso 自身が起動した所有権を検証済みのものだけ。手動で開いたブラウザを誤って閉じません）：

```bash
lasso chrome-stop          # 台帳にある Lasso 起動の Chrome をすべて閉じる
lasso chrome-stop --port 9222   # 指定ポートのものだけ閉じる
```

> 正直な境界線：`lasso launch-chrome` を単体で（サーバー経由なしで）実行した場合は idle 自動クローズがなく、出口は引き続き `chrome-stop` です。`browse_logged_in` が**自分で開いた可視 Chrome** に繋ぐ場合は「低ストレス、ただしゼロではない」（macOS 上流のプラットフォームレベル制限で、一部の操作が一度フォーカスを奪うことがあります）——完全にサイレントにしたいなら lasso 自身の hidden 案か `browse_headless` を使ってください。`desktop` チャンネルは実人のキーボード／マウスをエミュレートするため、**設計上、物理キーボードとマウスを占有します**——サイレントな形態はありません。

`browse_logged_in` があなたの Chrome で開いたタブは、タスク終了時に `admin {action:"tab_restore", reason:"タスク完了"}` と一言言えば、Lasso が開いたタブを閉じて元のタブ一覧を復元します（サーバー終了時にも自動実行）。ヘッドレスブラウザはデフォルトで **5 分使われなければ自動回収**——常駐してメモリを占拠しません。高頻度で連用してコールドスタートを節約したい場合は `LASSO_HEADLESS_IDLE_MS=3600000`（1 時間）；`0` で完全無効。

**詳細** → [キー設定ガイド · ログイン済みブラウジング](./doc/KEY-GUIDE.md#b-登录态浏览命令行配置无-key)。

### 3. デスクトップの操作（✅ 無料 · キー不要、OS で一度だけ認可）

**機能**：macOS / Windows / Linux のネイティブアプリを操作（クリック、入力、ウィンドウ内容の読み取り、ホットキーの実行）します。

**キーは必要か**：いいえ。

**設定方法**（OS を選んでください）：

- **macOS**：`lasso doctor` を一度実行し、案内に従って「システム設定 → プライバシーとセキュリティ」の **アクセシビリティ** と **画面収録** の両方で `lasso-rust-helper` にチェックを入れます。`doctor` が手引きするのでパスを探す必要はありません。
- **Windows**：Claude にデスクトップ操作を依頼した初回に、システムから認可プロンプトが表示されるので「許可」をクリック（macOS のアクセシビリティに相当）。
- **Linux**：アクセシビリティインターフェースがインストールされていることを確認（大半の GNOME / MATE デスクトップには標準で入っています。入っていなければ `sudo apt install at-spi2-core`）。

> **正直な境界線**：macOS は実機で検証済み、Windows / Linux はコンパイル時と契約レベルのセルフチェックを通過していますが、実機での網羅的手動テストはまだ進行中です。**「Win/Linux で完全検証済み」とは偽りません。**

**詳細** → [キー設定ガイド · デスクトップ操作](./doc/KEY-GUIDE.md#c-桌面控制系统授权无-key)。

### 4. クラウドブラウザ：セルフホストまたはホスト型（セルフホストは無料 / ホスト型は有料、デフォルトはオフ · 二重確認で有効化）

**機能**：Cloudflare や強力なアンチボットに守られたサイトをスクレイプします（軽度のアンチボットは `browse_headless` 内蔵のアンチ検出で通ります——ここは強力な相手専用）。

**キーは必要か**：どの経路によるかです。3 つのクラウドチャンネルから選べ、**キーが必要なのはホスト型だけ**：

- **(a) Steel セルフホスト（推奨 · 無料）**：ローカル Docker でオープンソースのクラウドブラウザを運用——**セッション単位費用ゼロ + cookie はローカルから出ない**。キーの申請は不要、自分で Docker を走らせるだけ。
- **(b) browserbase ホスト型（有料）**：100 分のトライアル後、従量課金。
- **(c) stagehand ホスト型（有料）**：AI 向けのページ観察。トライアル向け。⚠️ **プログラマティックな実験チャンネル**——キーを設定しても **MCP ツール入口はありません**（REST 契約はランタイム未検証。`lasso doctor` #39 が専用チェック）；実際にアンチボットを突破するなら Steel か browserbase を。

**設定方法**：以下の 2 条件を同時に満たすこと——

1. マスタースイッチ：`LASSO_ALLOW_CLOUD_BROWSER` を `true` に設定
2. 少なくとも 1 つのクラウドチャンネル——Steel（`STEEL_ENDPOINT` を設定）または browserbase（対応キーを設定）。stagehand のキーは内部実験チャンネルを組み立てるだけで、ツールは露出しません

**最短設定 · Steel セルフホスト（無料・推奨）**：

```json
{
  "LASSO_ALLOW_CLOUD_BROWSER": true,
  "STEEL_ENDPOINT": "http://localhost:3000"
}
```

Steel は Docker 一行で起動：`docker run -p 3000:3000 -p 9223:9223 ghcr.io/steel-dev/steel-browser`。完全な開通手順は [キー設定ガイド · Steel](./doc/KEY-GUIDE.md#steel_endpoint--自托管云浏览器v16-新推荐免费) を参照。

**最短設定 · browserbase ホスト型（有料）**：

```json
{
  "LASSO_ALLOW_CLOUD_BROWSER": true,
  "BROWSERBASE_API_KEY": "your_browserbase_key"
}
```

> デフォルトで完全オフ——設定しなければこの能力は存在しません。通常のページには不要で、**あなたが明示的に望んだ時だけ有効化されます**。軽度のアンチボットにはクラウドブラウザは全く不要——`browse_headless` の内蔵アンチ検出で十分です。

**ホスト型キーの申請方法、Steel Docker の開通方法** → [キー設定ガイド · クラウドブラウザ](./doc/KEY-GUIDE.md#d-云浏览器反爬默认关双重解锁) を参照。

<details>
<summary><b>高度なチューニング（任意——通常のユーザーは読み飛ばして OK）</b></summary>

日常利用では以下は **完全に無視して構いません**。これらは特殊シナリオ向けで、大半は `lasso config init` で `~/.lasso/config.json` に設定できるか、環境変数で上書きできます（環境変数は設定ファイルより優先されるので、一時的な差し替えに便利です）：

- ログイン済み Chrome のデバッグポートを変更（デフォルトの `9222` が取られている場合）
- キャッシュや状態ファイルの保存場所を変更
- 無料の検索ソースのみに制限
- 社内ネットや特定のプロキシレンジを許可
- ログイン Cookie を暗号化する独自パスフレーズを設定（未設定時は macOS Keychain を使用）
- 検索結果のスナップショットをディスクに保存（回帰テスト用）
- ヘッドレスブラウザの idle 自動回収時間を調整（`LASSO_HEADLESS_IDLE_MS`、デフォルト 5 分。`0` で無効）
- launch-chrome の Chrome の「使い終わったら閉じる」時間を調整（`LASSO_LAUNCH_IDLE_MS`、デフォルト 60 秒。`300000` で 5 分、`0` で無効）、または可視起動へ戻す（`LASSO_LAUNCH_MODE=visible`）
- ブラウザにアウトバウンドプロキシを設定（`LASSO_PROXY`、例：`http://127.0.0.1:7890`。**ヘッドレスブラウザと Steel クラウドブラウザにのみ影響——ログイン済み Chrome の出口は常に元のまま**——v1.11）
- Steel セルフホストクラウドブラウザのエンドポイントを設定（`STEEL_ENDPOINT`、例：`http://localhost:3000`。有効化には `LASSO_ALLOW_CLOUD_BROWSER=true` も必要）

変数の完全なリストとデフォルト値：[キー設定ガイド · 高度なチューニング](./doc/KEY-GUIDE.md#e-高级调优可选全不配)。**Surge / Clash などの TUN プロキシネットワーク（fake-ip、`198.18.0.0/15`）と `127.0.0.1`（ローカル Chrome の CDP デバッグポート用）は初期状態で許可済み**——追加設定は不要で、設定し忘れではなく設計意図です。

> **後方互換性**：以前 `claude mcp add -e KEY=VAL` でインストールしていた場合、それらの環境変数は **そのまま動作し**、設定ファイルを **上書き** します。設定ファイルは追加の、よりフレンドリーな経路にすぎません——環境変数を置き換えるものではありません。

## プライバシーとセキュリティ

あなたのデータはあなたのものです。

- **ログイン Cookie は絶対に外部に送出されません**——あなたが明示的に有効化し、ディスクに暗号化する場合を除いて。Lasso があなたのログイン状態をこっそりどこかへ送ることはありません。
- **デスクトップ操作のログはローカルに留まります**——リモートへの報告はゼロ。Lasso はあなたの行動を外に報告しません。
- **クラウドブラウザはデフォルトでオフ**——有効化には **明示的な二重確認**（マスタースイッチ + キー）が必要です。それがない限り、この機能は実質的に存在しません。
- **2FA / CAPTCHA / 認証コードの代行解除はしません**（レッドライン）。これらは必ずローカルのブラウザで、あなた自身が一度だけ通す必要があります。
- **外部者が社内サービスを勝手に叩くことはできません**——社内ネットへのアクセスはデフォルトで拒否。Surge / Clash の TUN プロキシネットワークは初期状態で許可済みです。
- **検索結果はデフォルトでディスクに書き込まれません**——記録モード（回帰テスト用）を明示的に有効化した場合のみ。

## トラブルシューティング

**どんな問題でも、最初の一歩は必ず `lasso doctor` です。** セルフチェックを行い、設定の不備を指摘してくれます。

| 症状 | 対処 |
|---|---|
| macOS のデスクトップ操作が動かない | 「システム設定 → プライバシーとセキュリティ → アクセシビリティ / 画面収録」で `lasso-rust-helper` にチェックを入れる（`lasso doctor` が案内します） |
| ログイン済みページのスクレイプが失敗する | ローカルの Chrome で一度手動でログイン（2FA も自分で通す）してから、「ログイン済みの X を開いて」と言う |
| PDF 保存が失敗する | 代わりに「このページの全体スクリーンショットを撮って」と言う |
| 検索がいつも空で返ってくる | キーの有効期限や無料枠の使い切りを確認。複数プロバイダー（Zhipu + Brave + Bing）を追加すると失敗率が劇的に下がります |
| リンクが開かない | 「このリンク切れてるからアーカイブを探して」と言って Internet Archive を確認 |
| 社内ネットへのアクセスがブロックされたと表示される | URL を再確認。TUN プロキシネットワークはデフォルトで許可されていますが、その他の社内ネットには明示的な許可が必要です |
| アンチ検出の効果を確認したい | `lasso doctor --stealth-check` を実行——creepjs 検出ページを駆動してベースラインと比較します（任意、日常利用には影響なし） |

完全な FAQ とデバッグのヒントは [`doc/TROUBLESHOOTING.md`](./doc/TROUBLESHOOTING.md) にあります。

## こんな人に向け・むいていない人

**むいている人**

- **Claude Code をヘビーに使う人**——毎週検索・スクレイプ・デスクトップ操作をし、用途ごとに別の MCP を入れたくない人
- **研究者 / レポート作成者 / データ系の人**——検索から整ったテキストの取得、リンク切れの復元までを一気通貫で
- **RAG / ナレッジベースを構築する人**——ウェブページを整った markdown + 引用マーカー付きに変換し、トークンも費用も節約
- **自動化 / DevOps 系の人**——macOS のネイティブアプリを操作し、ログイン済みの社内ダッシュボードをスクレイプ
- **ログイン済みページをよくスクレイプする人**——ローカルの Chrome セッションを再利用、設定に認証情報を再保存する必要なし

**むいていない人**

- **Claude Code やその他 MCP クライアントを使っていない人**——Lasso は MCP サービスであり、動作には MCP クライアントが必要です
- **単一の機能だけが必要で、すでに専用ソリューションを持っている人**——オールインワンは冗長になる可能性があります
- **2FA / CAPTCHA の回避を探している人**——レッドラインです。やらないし、これからもやりません
