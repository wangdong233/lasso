### 2.1 根因确认（需求单事实 × 本仓库事实交叉）

1. **Chrome 155 起 profile Preferences 的 `intl.accept_languages` / `intl.selected_languages` 优先级高于 `--lang` / `--accept-lang` / 系统 locale**（需求单三条命令行路径实测全灭）。本机佐证：`~/.cache/lasso/chrome-profile-default/Default/Preferences` 实测已含 `intl: {accept_languages: "zh-CN", selected_languages: "zh-CN,zh"}`——键形态与需求单方案 A 一致。
2. **该 profile 属 lasso 托管**：日常档 `~/.cache/lasso/chrome-profile-default`（`defaultChromeProfileDir()`，launch-chrome.ts:249）、登录档 `~/.cache/lasso/login-chrome-profile/<ns>`（login-flags.ts:38-41）。写入的合规属主只有 lasso。
3. **两档都要接入**：日常档（launch-chrome.ts）是需求方验收命令的字面目标，也是采集回归的正确路径（见回复要点 1）；登录档（login-bridge/launcher.ts，自己的 spawn 引擎）承载登录接力。只改一档解不了完整需求。
4. **参数保真**：`--extra-args` 通道 launch-chrome 已有（parseLaunchChromeArgs :935）；登录档没有（args = LOGIN_FLAGS + 4 项固定拼装，launcher.ts:331-337）。config 键 `LASSO_LAUNCH_EXTRA_ARGS` 补齐持久层。**注意（v2，审查 B-F1/C-1 双确认）：config 键用空白符拆分，不能用 `--extra-args` 的逗号拆分**——需求方第一参数 `--window-size=1920,1080` 自身含逗号，逗号拆分会产出残缺 flag + 裸位置参数。CLI `--extra-args` 既有逗号语义不动（向后兼容），文档标注其逗号局限。
5. **QUIC**：需求方要求**不要** `--disable-quic`——两档默认 flags 均无 QUIC 开关（launch-chrome.ts:537-547 / login-flags.ts LOGIN_FLAGS），天然合规，零动作。

**Step 3 实现**（INV-64：仅 node:fs/node:path；结果类型瘦身 `{ok:true}|{ok:false;error}`；原子写）：

```typescript
import { existsSync, mkdirSync, readFileSync, renameSync, writeFileSync } from "node:fs";
import * as path from "node:path";

export interface ProfileLocalePrefs { acceptLanguages: string; selectedLanguages: string; }

/** locale tag → Preferences 两键值；非法返 null。大小写规范化：primary 小写、region 大写（zh-cn→zh-CN）。推荐区域限定 tag（en-US 而非 en）。 */
export function localePrefValues(tag: string): ProfileLocalePrefs | null {
  if (!/^[a-zA-Z]{2,3}(-[a-zA-Z0-9]{2,8})*$/.test(tag)) return null;
  const norm = tag.split("-").map((p, i) => (i === 0 ? p.toLowerCase() : p.toUpperCase())).join("-");
  const primary = norm.split("-")[0];
  const base = norm.includes("-") ? `${norm},${primary};q=0.9` : `${norm};q=0.9`;
  return { acceptLanguages: base, selectedLanguages: norm };
}

export type ProfilePrefsWriteResult = { ok: true } | { ok: false; error: string };
```
