# BUG-14 visible 调试实例跨会话滞留:消费方会话遗留可见浏览器窗口

> 日期:2026-09-23 | 报告方:**用户亲历**(会话「cc技能_media-gen-mcp」使用过程中浏览器未隐藏)
> 级别:待定级(非数据损坏;用户观感=「lasso 开的窗口不该一直挂着」)
> 关联:BUG-13(同一消费方调研事件;治理面 vs 消费方可视面的同族断层)

## 1. 现场事实(主循环 2026-09-23 核查)

chrome-ledger 台账现存唯一实例:

```json
{
  "port": 9225, "pid": 38789,
  "profileDir": "~/.cache/lasso/chrome-profile-default",
  "launchedAt": 1790079122062,  // 2026-09-22(gemini 调研)
  "launchMode": "visible",      // ← 消费方会话显式传 --mode visible
  "idleMs": 0,                  // ← 显式传 --idle-ms 0(永不回收)
  "ownerKind": "cli", "ownerPid": 38787
}
```

- 该实例即 BUG-13 报告 §2 步骤 3 的 gemini 调研实例(launch-chrome --port 9225 **--mode visible** --idle-ms 0);
- 调研次日(09-23)窗口仍可见挂在桌面——用户观感为「lasso 开的浏览器没有隐藏」。

## 2. 初步定罪方向(白盒/红队前的工作假设)

1. **非 hidden 模式失效 bug**——hidden 语义正常;是消费方会话为登录配合显式选了 visible;
2. **真缺口=visible+idle-0 组合的跨会话滞留治理**:
   - lasso 已有 chrome-hide(活的 visible 实例降回静默)/chrome-show,但**消费方不可见**(工具发现面断层);
   - 无任何「调研结束后收尾」提醒/机制——实例设计上跨会话存活(idle 0 是 feature),但可见性不收;
   - doctor 是否报长驻 visible 实例?待白盒核查。

## 3. 候选修复方向(待工作流裁决,不预设)

- doctor check 增加「长驻 visible 实例」提示行(可见性治理面);
- chrome-status 输出补 visible 实例的收尾建议(chrome-hide 一行命令);
- 消费方文档(README/KEY-GUIDE)补「visible 调试用毕收尾」段落;
- 不做:自动隐藏/自动回收(违背 idle-0 显式语义——用户/消费方明确要长驻时 lasso 不替人决定,同 input_guard 哲学)。
