# 12 - 下载器纳入决议与 BT 可行性定谳（2026-09-20）

> 消费方发起：luceo 媒体语料管线（`luceo/doc/lasso下载器集成建议_2026-09-20.md`，一手实测证词）。
> 调研：三路并行（架构白盒 / BT 独立验证含真机实测 / 引擎开源生态）+ 红队对抗（GO-WITH-CONDITIONS 十条）。
> 本文件 = v1.30 实施真源。**与本文冲突的直觉/记忆一律以本文为准。**

## 一、纳入判定：GO

1. **动词族闭合**：search（发现）→ browse（阅读）→ fetch_url（≤16MiB 小体量字节流）之后，「资源到磁盘的获取」是既有动词族的未完成面而非新领域——16MiB 帽是刻意的 context 保护（`fetch-url.ts:57`），下载到磁盘不进 context 是正交能力，扩 fetch_url 帽是错误方向。
2. **消费方证据**：luceo 每轮 GB 级语料，「让下载跑起来」净时间 2h（管线代码 40min，其余环境对抗）；AIGC 工作流同需求。九家消费方事故源之后第十类共性面。
3. **media-gen-mcp 不对口**：无 chrome-ledger/kill-tree/dir-allowlist/ssrf-guard 任一底座，从零重造即重复 INV 纪律。
4. **协同独有价值**：browse_logged_in × download（网盘/登录态站→真实 URL→引擎）纯下载 MCP 做不到。

## 二、BT 可行性定谳（真机实证，2026-09-20 本机直连）

- **裁决**：用户直觉「按理应该没问题」在开放互联网成立；**本机（广东移动家宽）不成立**——运营商区域级、BT 协议特征级（DPI）定向封锁。证据四重：①STUN/UDP 通（203ms）但 BT-UDP（12 tracker BEP15+DHT bootstrap）全超时=选择性阻断非端口封锁；②明文 peer wire 握手 0/14（US/JP/AU/BR/大陆 peer 真实地址）；③transmission-cli 4.1.3 真实客户端 110s 零 peer；④aria2c 三配置同零。外部互证 XTLS/BBS#18（广东移动同症、江西移动正常）。
- **luceo 三死因修正**：DNS 污染**仅限 DHT bootstrap 域名**（router.bittorrent.com 等 4 个；且阿里 DoH 同吐假 IP——递归上游污染，**IP 直写才是解**，DoH 不是）；tracker 域名未被污染；「代理出口 502」实为机场对 BT announce 限流。
- **三个活口**（未测/条件）：IPv6 直连（本机有公网 2409:8a55，DPI 可能只在 v4 侧）；代理 TCP-only+强制加密（qBittorrent 系才支持 peer 代理，aria2 不支持）；换运营商出口。
- **aria2 BT 定位**：非主力（peer_id 被 Ubuntu 官方 tracker 封禁、announce 串行慢、无 peer 代理、无 uTP）——**「诊断即功能」降格**：60s 零 peer 报**双因**（死种 OR DPI 封锁，禁单因断言）+三出路建议（改道 HTTP/stream kind / IPv6 试探属用户侧 / 换网络出口），诊断知识编码进 error 面（input_guard_suspected 同款诚实信号哲学）。bundled 冻结 tracker 列表一份即止，**不做列表维护跑步机**。

## 三、架构决议（红队修正后）

| # | 决议 | 依据 |
|---|---|---|
| D1 | 单工具 `download(action: start\|status\|wait\|cancel)` action-enum | INV-17/admin 正典；预算决定性 |
| D2 | 独立工具族（fetch_url/search_local 范式），**不建 DownloadChannel** | 无 fallback 语义/breaker 需求；INV-23 caller-tier |
| D3 | **per-task spawn，RPC daemon 出局 v1** | 续传载体=.aria2 控制文件+`-c` 非 GID 连续性；daemon 引入 port+secret+singleton 新面（违 bug06 幽灵治理精神）；daemon 列为实证不足后的升级项 |
| D4 | detached 引擎跨 lasso 重启存活；shutdown **默认不杀只标 orphaned**；status 触发 reconcile 收养 | render-chrome 先例同款（台账共有制+cmdline 复验） |
| D5 | **stdio 文件化**（fs.openSync fd / 日志文件重定向），进度=tail 解析机读格式；**禁 stdio pipe**（lasso 死后 SIGPIPE 自毁=H1 技术死穴） | 红队 H1，不满足即回炉 |
| D6 | 任务表每任务一文件 `~/.cache/lasso/downloads/tasks/<taskId>.json`（chrome-ledger 纪律：tmp+rename 原子写/损坏读→跳过/ownerPid/env 可覆盖） | 红队 H6；StateStore LRU 淘汰语义不适 authoritative state |
| D7 | cancel 杀谓词=任务定向：台账在案+pid 活+cmdline 含 lasso marker+taskId 匹配 → killTreeSync 单一真源；新 INV 钉死 | 红队 H10/kill 红线 |
| D8 | wait timeout_s zod 帽 ≤120s，超时返 partial 快照+outcome=unknown 可续轮询 | 红队 H3/MCP 超时+反 stall 家法 |
| D9 | 引擎栈：aria2c（HTTP 多线程+BT）+ yt-dlp（stream）+ undici 单流（引擎全缺降级） | 引擎调研 Z'；本机 brew aria2 1.37.0 已在 |
| D10 | 引擎引导 lazy opt-in（首 download 调用才拉）；yt-dlp_macos standalone→`~/.cache/lasso/bin/`；aria2 检测序 PATH→conda-forge 引导；**sha256 常量进仓库**（禁安装时现取——TOCTOU）；doctor 报版本/发布龄 | 红队 A1-刺②/§3.1 |
| D11 | proxy=auto 三级显式：`LASSO_PROXY`（若有）→ env `HTTP(S)_PROXY`（若有）→ off；undici 降级路显式 EnvHttpProxyAgent 对齐；分叉写 doc | 红队 H7 |
| D12 | 安全面：http kind 全量 ssrfGuard（同 fetch_url 同函数同 config）；stream kind 诚实边界（网络面由 yt-dlp 决定：extractor 页+多 CDN+引擎自跟随重定向——**INV 文本写明不假装守住**）；magnet/torrent 独立 INV（DHT peer 含私网 IP=ssrfGuard 私网姿态显式放弃面）；out_dir 白名单（dir-allowlist realpath 双侧+path-boundary 模板，默认 `~/Downloads`+`LASSO_DOWNLOAD_DIR_ALLOWLIST`）；filename 强制 basename（禁 `/`、`..`）；max_bytes 默认 5GiB=Content-Length 预检+chunked 未知长 watchdog（超限 killTree+标 oversize） | 红队 H4/H5/H8/§3 |
| D13 | 孤儿三件套（红队 H2，不满足即回炉）：doctor+status:"all" 可见 / cancel 可关 / 硬顶（任务级 idle 硬顶+总量帽） | bug06 同型防线 |
| D14 | 进度协议锁机读：yt-dlp `--newline --progress-template "download:%(info.id)s\|%(progress._percent_str)s\|..."`；aria2c `--summary-interval=5`+`--download-result=hide`+日志文件解析；**fixture 假引擎锁定协议**（CI 无真引擎，creepjs-baseline 先例） | 红队风险2 |
| D15 | 字幕默认 json3（luceo §2.3 陷阱：vtt/srt=滚动重复 2.6×）；`--js-runtimes node` 显式透传 | 消费方一手 |
| D16 | BT kind 路由保留但 v1 直连形态（DHT bootstrap IP 直写+bundled tracker 表）；诊断即功能 | §二 |

## 四、工具面契约

```
download(action:"start", url, {kind?: auto|http|stream|torrent, out_dir?, filename?,
        proxy?: auto|"host:port"|off, subs?: bool, audio_only?: bool,
        max_conn?: 1-16, max_bytes?: number}) → task_id + 初始状态
download(action:"status", task_id | "all") → 任务数组（含 files 产物绝对路径——跨会话交付物本体）
download(action:"wait", task_id, {timeout_s?≤120}) → 终态或 partial 快照+outcome=unknown
download(action:"cancel", task_id) → bool
```

- kind=auto 路由：`magnet:`/`.torrent`→torrent；yt-dlp extractor 域名特征→stream；其余→http。
- 非法组合显式报错+`ignored_options` 回显（家法先例）。
- task_id=lasso 生成 UUID 落盘；跨会话寻址靠 `status:"all"`。

## 六、Rejected-by-design（v1）

- BT 协议自研 / uTP 自研（aria2/libtorrent 已是业界最佳，自研=疯狂）。
- RPC daemon 形态（D3——实证不足，v2 再议）。
- tracker 列表自动更新（维护跑步机；bundled 冻结即止）。
- 网盘站直解（第二期：browse_logged_in 找 URL→download http/stream，浏览器会话与下载引擎各司其职）。
-迅雷 GUI 通道（官方 4KB/s 限速+无 CLI 面）。
- webtorrent 引擎（node-datachannel Monterey 崩+git 依赖地狱）。
- yt-dlp `-U` 自更新（不可审计；exit 1+extractor 失效词触发重引导 latest+sha256）。

## 七、验收（消费方量化标准，luceo §五）

| 维度 | 判据 |
|---|---|
| 通用 | 直链/流媒体/磁力/本地 .torrent 四形态端到端；HTTP 冒烟=真 spawn aria2c 下载真文件（SLOW_SPECS）；BT=fixture+本机双因诊断面 |
| 高效 | 断点续跑（kill 引擎后重 spawn 字节级继续）；并行 ≥4 互不阻塞（任务表每任务一文件无锁竞争） |
| 快速 | 错误路径快失败（BT 死路 ≤60s 报因）；status <50ms（读任务文件非进程）；wait 帽 120s+轮询教学 |
| 治理 | 孤儿三件套（doctor 可见/cancel 可关/硬顶）；kill 谓词 INV；零 stdio pipe |
