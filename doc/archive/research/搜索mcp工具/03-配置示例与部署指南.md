# 03 · 配置示例与部署指南

> 可直接复制的配置。按本机优先级排列。所有命令针对 **Claude Code**（其他 MCP 客户端逻辑相同，改 JSON 即可）。

---

## 前置：MCP 配置放在哪？

| 作用域 | 位置 | 命令 |
|---|---|---|
| **当前项目** | `.mcp.json`（项目根） | `claude mcp add ...`（默认项目级） |
| **当前用户（全局）** | 用户配置 | `claude mcp add -s user ...` |

> 推荐搜索类用 `-s user`（全局），所有项目共享。

**验证已注册**：
```bash
claude mcp list
```

---

## A. One Search MCP（🥇 推荐主力，支持中文）

### A1. local 模式（复用本机浏览器，免费无 Key，支持百度/搜狗）
```bash
claude mcp add -s user one-search \
  -e SEARCH_PROVIDER=local \
  -- npx -y one-search-mcp
```

### A2. duckduckgo 模式（更轻，纯英文）
```bash
claude mcp add -s user one-search \
  -e SEARCH_PROVIDER=duckduckgo \
  -- npx -y one-search-mcp
```

### A3. 等价 .mcp.json 片段
```jsonc
{
  "mcpServers": {
    "one-search": {
      "command": "npx",
      "args": ["-y", "one-search-mcp"],
      "env": {
        "SEARCH_PROVIDER": "local"   // 或 "duckduckgo"
      }
    }
  }
}
```

### A4. 将来升级（拿到 Key 后平滑切换后端）
```jsonc
"env": {
  "SEARCH_PROVIDER": "zhipu",          // 或 exa / tavily / bing / google / bocha
  "ZHIPU_API_KEY": "你的key"
}
```

> `local` 模式会自动检测本机 Chrome/Edge/Chromium/Chrome Canary，无需手动指定路径。

## B. mcp-web-search（🥈 三源自动 fallback）

```bash
claude mcp add -s user web-search -- npx -y @zhafron/mcp-web-search
```

等价 .mcp.json：
```jsonc
{
  "mcpServers": {
    "web-search": {
      "command": "npx",
      "args": ["-y", "@zhafron/mcp-web-search"]
    }
  }
}
```

> 默认走 DuckDuckGo（无需浏览器）。fallback 链：DDG → SearXNG → Bing 自动降级。

## C. Jina AI MCP（🥉 兜底全文阅读）

### C1. 不带 Key（仅 read_url / screenshot，免费 20 RPM）
```bash
claude mcp add -s user --transport http jina https://mcp.jina.ai/v1
```

### C2. 带免费 Key（解锁 search_web 等，1000 万 token）
```bash
# 先拿 Key：https://jina.ai
claude mcp add -s user --transport http jina https://mcp.jina.ai/v1 \
  --header "Authorization: Bearer ${JINA_API_KEY}"
```

等价 .mcp.json：
```jsonc
{
  "mcpServers": {
    "jina": {
      "type": "http",
      "url": "https://mcp.jina.ai/v1",
      "headers": {
        "Authorization": "Bearer 你的JINA_API_KEY"   // 可省略 → 仅阅读类工具
      }
    }
  }
}
```

## E. duckduckgo-mcp-server（务必装 [browser] extra）

### E1. 安装（带 browser extra，绕过 TLS 封锁）
```bash
pipx install "duckduckgo-mcp-server[browser]"
```

### E2. 注册到 Claude Code
```bash
claude mcp add -s user ddg -- uvx --from "duckduckgo-mcp-server[browser]" duckduckgo-mcp-server
```

### E3. 等价 .mcp.json
```jsonc
{
  "mcpServers": {
    "ddg": {
      "command": "uvx",
      "args": ["--from", "duckduckgo-mcp-server[browser]", "duckduckgo-mcp-server"],
      "env": {
        "DDG_SEARCH_BACKEND": "auto",   // httpx 失败回落 curl
        "DDG_REGION": "wt-wt"           // 或 "cn-zh" 等
      }
    }
  }
}
```

> ⚠️ 不装 `[browser]` extra 会偶发静默返回空结果（TLS 封锁）—— 见 [02](02-候选方案详解.md#5-duckduckgo-mcp-server--nickclydeduckduckgo-mcp-server)。

## F. SearXNG 系（需 Docker，本机暂不推荐）

### F1. whw23/searxng_http_mcp（自包含 Docker）
```bash
# 拉取并运行（SearXNG 已内置）
docker run -d --name searxng-mcp -p 8080:8080 ghcr.io/whw23/searxng_http_mcp

# 注册到 Claude Code（HTTP 传输）
claude mcp add -s user --transport http searxng http://localhost:8080/mcp
```

### F2. ihor-sokoliuk/mcp-searxng（broker，指向既有实例）
```bash
claude mcp add -s user searxng \
  -e SEARXNG_URL="https://你的searxng实例.example.com" \
  -- uvx mcp-searxng
```

等价 .mcp.json：
```jsonc
{
  "mcpServers": {
    "searxng": {
      "command": "uvx",
      "args": ["mcp-searxng"],
      "env": {
        "SEARXNG_URL": "https://你的searxng实例.example.com"
      }
    }
  }
}
```

> ⚠️ 本机未装 Docker，F1 暂不适用。若要用 F2，需先有可访问的 SearXNG 实例（自建或公共）。

## 🌟 推荐组合（本机最优，直接抄）

**主力（中文搜索）+ 兜底（全文阅读）**，写到用户全局配置：

```jsonc
// ~/.claude.json 或 claude mcp add -s user 逐条添加
{
  "mcpServers": {
    // 主力：中文搜索，免费无 Key，复用本机浏览器
    "one-search": {
      "command": "npx",
      "args": ["-y", "one-search-mcp"],
      "env": { "SEARCH_PROVIDER": "local" }
    },

    // 兜底：网页全文/截图，远程托管，免 Key 20 RPM
    "jina": {
      "type": "http",
      "url": "https://mcp.jina.ai/v1"
      // 想解锁 search_web 就加 "headers": { "Authorization": "Bearer 你的KEY" }
    }
  }
}
```

**逐条命令版**（更省事）：
```bash
claude mcp add -s user one-search -e SEARCH_PROVIDER=local -- npx -y one-search-mcp
claude mcp add -s user --transport http jina https://mcp.jina.ai/v1
```

## 验证与故障排查

### 1. 检查是否注册成功
```bash
claude mcp list
```
应看到 `one-search`、`jina` 等条目。

### 2. 在 Claude Code 里测试
对话中直接让它搜索，观察是否调用了对应工具（如 `mcp__one-search__*`）。

### 3. 常见问题

| 症状 | 排查 |
|---|---|
| `npx` 找不到 | 装 Node.js（含 npx）；或改用 `uvx`（Python 系方案） |
| One Search `local` 模式不工作 | 确认本机装了 Chrome/Edge/Chromium 之一；浏览器版本别太旧 |
| DDG 返回空结果 | 装上 `[browser]` extra（见 E1），或设 `DDG_SEARCH_BACKEND=auto` |
| Jina `search_web` 报 Authentication failed | 该工具需 Key（阅读类 `read_url` 不需要） |
| Exa 频繁 429 | 免费层 ~1000/月已耗尽，换 One Search 或 Jina |
| 内存告警（本机 8GB） | `local` 浏览器模式较吃内存，可临时切 `duckduckgo` 模式 |

### 4. 移除某个 MCP
```bash
claude mcp remove one-search
```
