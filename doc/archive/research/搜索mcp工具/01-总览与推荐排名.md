# 01 · 总览与推荐排名

## 一、核心结论

真正"免费 + 高性能 + 稳定 + 好用"的 Search/WebSearch MCP，落在**三类**：

| 类别 | 代表方案 | 特征 |
|---|---|---|
| **① 纯本地 / 无 Key 聚合型** | One Search MCP、mcp-web-search、duckduckgo-mcp-server | 零成本零 Key，本地运行，依赖免费搜索源（DDG/浏览器自动化） |
| **② 自建 SearXNG 型** | whw23/searxng_http_mcp、ihor-sokoliuk/mcp-searxng | 聚合 200+ 引擎，最稳定，但需运维（Docker / 既有实例） |
| **③ 部分免费托管型** | Jina AI MCP、Exa MCP | 远程托管零运维，部分功能免 Key，搜索类常需免费 Key |

> **结合本机（8GB / 无 Docker）**，第①类落地成本最低，是首选；第②类暂缓；第③类作为补位/兜底。

## 三、按场景的决策树

### 场景 A：日常中文搜索（你当前最可能的场景）
→ **One Search MCP**（`SEARCH_PROVIDER=local`）
- 复用本机已装的 Chrome/Edge，支持百度/搜狗/Bing/Google
- 完全免费、无 Key、本机原生

### 场景 B：纯英文 / 极简 / 不要浏览器依赖
→ **mcp-web-search**
- 默认走 DuckDuckGo，无需浏览器进程
- DDG→SearXNG→Bing 三源自动 fallback，单点失败不中断

### 场景 C：需要抓取网页全文 / 截图 / PDF 抽取
→ **Jina AI MCP**（不带 Key 即可用 `read_url` / `capture_screenshot_url`）
- 远程托管，零运维
- 19 个工具，返回质量全场最丰富

### 场景 D：最低接入摩擦（<1 分钟跑起来）
→ **Exa MCP**
- 远程 URL `https://mcp.exa.ai/mcp`，粘贴即用
- ⚠️ ~1000 req/月，高频会 429；有用户反馈稳定性问题

### 场景 E：生产级 / 高频 / 长期稳定（需服务器）
→ **whw23/searxng_http_mcp**（自建 SearXNG）
- 聚合 200+ 引擎，最抗封
- ⚠️ 需 Docker，本机暂不友好

### 场景 F：已有免费 Key，想要更好的搜索质量
→ **Brave Search MCP**（2000 次/月免费）或 **Tavily**（1000 credits/月免费，Agent Score 13.67，延迟 998ms）
- 见 [04-性能基准与免费额度对比.md](04-性能基准与免费额度对比.md)

## 四、免费性分级（重要 —— 别被"免费"误导）

| 级别 | 含义 | 方案 |
|---|---|---|
| 🟢 **完全免费 / 零 Key** | 无需任何注册，开箱即用 | One Search (local/ddg)、mcp-web-search、duckduckgo-mcp-server、SearXNG 系（但需自建） |
| 🟡 **部分免费 / 需免费 Key** | 要注册拿免费 Key，或有月额度 | Jina（阅读免 Key，搜索需 Key）、Exa（远程 URL 免 Key，~1000/月）、Brave（2000/月）、Tavily（1000 credits/月） |
| 🔴 **付费** | 无免费层或免费层极小 | Perplexity MCP、Serper、大部分企业级 |

> Jina 的 10M 免费 token 据条款**限非商业用途**；SearXNG 本体是 **AGPL-3.0** —— 商用务必复查条款（见 [06-局限与开放问题.md](06-局限与开放问题.md)）。

## 五、给本机的最终建议组合

**两个互补，零运维零成本，覆盖全场景：**

| 角色 | 方案 | 解决什么 |
|---|---|---|
| 🅰️ **主力搜索** | One Search MCP（`local`） | 中文 + 多引擎 + 免费无 Key |
| 🅱️ **兜底全文** | Jina AI MCP（无 Key） | 网页全文/截图/PDF，免费 20 RPM |

配置直接抄 [03-配置示例与部署指南.md](03-配置示例与部署指南.md) 的「推荐组合」一节。

将来若上专用服务器 + Docker，再追加 SearXNG 作为最稳定后端。

## 六、为什么不推荐某些"热门"方案（在本机语境下）

| 方案 | 不推荐（本机）的原因 |
|---|---|
| Brave Search MCP | 要免费 Key（2000/月），非零 Key；质量好但本机并非最优起点 |
| Tavily | 要免费 Key（1000 credits）；2026-02 被 Nebius 收购，免费层长期存续有风险 |
| Perplexity MCP | 付费；基准延迟 11+ 秒，不适合交互 |
| Serper / Google CSE | 需付费 Key |
| SearXNG 系 | 质量最稳但需 Docker，本机落地成本高 |

> 这些不是"差"，而是**在当前机器 + 当前诉求（免费/零运维）下不是最优起点**。换环境可能反转。
