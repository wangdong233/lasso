# 05 · 避坑 —— 被对抗核验否决的误导结论

> 调研中有 2 条声明被 **3 票全否（0-3）** 剔除。记录下来，避免你被网上同款说法误导。

**核验机制**：每条声明由 3 个独立 agent 分别尝试**反驳**；≥2 票反驳即"杀死"该声明。0-3 意味着 3 个 agent 一致认为它站不住。

---

## ❌ 误导结论 1：「Brave 是全场最优推荐，Perplexity 全场最慢」

### 原始说法
> "Brave Search achieved the highest Agent Score (14.89) of 8 tested APIs and the lowest average latency (669ms), making it the top recommendation for production AI agents with balanced requirements."

来源：[AIMultiple](https://aimultiple.com/agentic-search)

### 否决结果：`0-3`（3 票全否）

### 为什么被否决
- **因果过度延伸**：基准确实测出 Brave 延迟最低、Agent Score 最高，但"全场最优推荐"是一个**因果归因**，超出了单一基准能支撑的范畴。
- 该基准只覆盖 8 个 API、100 个 query、单一评判模型（GPT），不足以推出"生产环境最优"这种强结论。
- "Perplexity 全场最慢故不推荐"同理被否——延迟数字可信，但归因不可信。

### 真相（保留的部分）
- ✅ **可信**：Brave 延迟 669ms、Agent Score 14.89；Tavily 998ms、13.67；Perplexity 11+ 秒。延迟跨度 20 倍。
- ❌ **不可信**：基于此推出"Brave 是生产最优选"。

### 教训
看到"X 是最佳推荐"时，检查它是否**只来自单一基准 + 单一评判方**。延迟/分数可以采信，"最优推荐"需多源交叉。

## ❌ 误导结论 2：「mcp-searxng 免费，而 Brave/Exa/Firecrawl 全需付费 Key」

### 原始说法
> "mcp-searxng is free and requires no API key, whereas the Brave, Exa, and Firecrawl MCP servers all require paid API keys."

来源：[ihor-sokoliuk/mcp-searxng README](https://github.com/ihor-sokoliuk/mcp-searxng)（对比表）

### 否决结果：`0-3`（3 票全否）

### 为什么被否决
这是**两处事实错误叠加**的误导性对比：

1. **夸大了 mcp-searxng 的"免费"**：
   - mcp-searxng 本身**不是搜索引擎**，也不能作为 SearXNG 插件运行。
   - 它只是个 **broker**，**必须**指向一个已存在的 SearXNG 实例（`SEARXNG_URL`）。
   - 也就是说，它的"免费"前提是你**先自建或借用一个 SearXNG 实例**——这个前置成本被隐藏了。

2. **错误地暗示 Brave/Exa 没有免费层**：
   - Brave 有 **2000 次/月免费层**（需免费 Key，但不付费）。
   - Exa 有**远程 URL 免 Key 免费层**（~1000 req/月）。
   - 说它们"全需付费 Key"是不准确的。

### 真相（修正后）
| 方案 | 免费情况 |
|---|---|
| mcp-searxng | 免费但**必须自建/借用 SearXNG 实例**（隐含运维成本） |
| Brave | 有 2000 次/月免费层（需免费 Key） |
| Exa | 有远程 URL 免 Key 免费层（~1000/月） |
| Firecrawl | 确实以付费为主 |

### 教训
- 警惕项目 README 里的**自家对比表**——有自利倾向。
- "免费"要追问：**免 Key ≠ 零成本**（可能要自建实例）；**需 Key ≠ 付费**（可能有免费额度）。
- mcp-searxng 的 broker 定位必须搞清楚，否则会以为"装了就能搜"。

---

## 📌 总结：两条通用防坑原则

1. **"最优推荐"需要多源交叉**：单一基准（哪怕方法论透明）只能支撑延迟/分数，支撑不了"最优"。
2. **"免费"要追问前置条件**：是否要自建？是否要 Key？Key 是否免费？额度多少？—— 四个问题问完才算看清。
