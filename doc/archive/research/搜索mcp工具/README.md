## 🏆 快速决策（3 行）

1. **中文 / 通用主力** → `One Search MCP`（`SEARCH_PROVIDER=local`，复用本机浏览器，免费无 Key，支持百度/搜狗）
2. **纯英文 / 极简** → `mcp-web-search`（DDG 默认，三源自动 fallback）
3. **全文阅读兜底** → `Jina AI MCP`（不带 Key，`read_url` 免费 20 RPM）

完整配置见 [03-配置示例与部署指南.md](03-配置示例与部署指南.md)。

## ⚠️ 重要前置约束（来自本机环境记忆）

- 本机 **8GB 内存、日常占用 ~94%、未装 Docker** → SearXNG 自建系（需 Docker）落地成本高，**优先选原生二进制方案**。
- 内存吃紧时网关类进程易触发 503（瞬时峰值，直接重试，勿调高阈值）。
- 已有偏好：智谱 GLM Coding Plan 优先（One Search MCP 的 `zhipu` provider 可作为未来补位，需 Key）。
