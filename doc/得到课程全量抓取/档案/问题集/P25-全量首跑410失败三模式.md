## 1. 模式① — qc_failed:+promo-present（48+2 章）

### 根因（白盒实证）

宣传图删除判据 **M3 是文件名日期前缀正则** `/2017022\d{12,}\.(jpg|png)/`，过拟合到首批上传日期（2017-02-2x）。
课程方对**同一张宣传图（md5 恒 `7127ed55…`）分批重传**，文件名日期前缀漂移到 201703…/201704…：
全量日志实测 **62× M3=false vs 3× M3=true**（`logs/produce-full.nohup.log`）。

```
[promo-audit] M2=true M3=false M4=true decision=keep-watch
[fix-screen]  skipped=[{"why":"last-fig-not-promo","m3":false,"src":"201703010732046707324132.jpg",...}]
[QC] promo=1 → FAIL +promo-present          ← 图没删，QC pdfimages 抓到 1080×607
```

对照组（成功章 e0007-meta.json，第005讲）：promo src `201702241658370213163918.jpg` 恰为 2017022 前缀 → M3=true → 删成。
**即判据在"赌文件名"，同一张图换个上传日期就漏删。** promo 与内容图同用 umiwi 数字命名，文件名不承载语义。

### 修法（engine.mjs，判据改内容寻址）

- `JS_PROMO_AUDIT` 后引擎侧本就 fetch srcAbs 算 md5（既有逻辑，此前只记录不参与裁决）→ 现在作为**删除主判据**：
  `promoDropOk = (md5 === PROMO_MD5)`。
- `JS_FIX_SCREEN` 参数化 `(promoDrop)`：末图删除条件 `M2(1080×607) ∧ M4(尾部无文) ∧ (promoDrop ∨ M3)`；
  M3 降级为 md5 取数失败（网络异常）时的兜底通道。删除日志带 `by:'md5'/'m3'` 便于审计。
- QC 门禁②不动（出厂 pdfimages 无 1080×607），继续兜底未知变体宣传图。

### 复验

`--only 第008讲丨商业是最大的慈善`：`promo-audit M3=false … md5=7127ed55(match)` → `dropped=1` →
`[QC] missing=[] inOrder=true promo=0 holes=0 pages=4 sikao=0/0` 全绿，PDF+MD 落产物目录。

## 2. 模式② — eval_unparseable（18）+ assert_failed:title-mismatch（23）

### 根因 A：eval_unparseable = lasso evaluate preview 4000 字符硬上限

白盒链路（lasso `src/channels/BrowseChannel.ts`）：

```
doEvaluate: preview = v(字符串全文) → truncatePreview() 截到 PREVIEW_MAX_CHARS=4000（硬编码，无 env 覆盖）
  → writeState 落盘 content_path 的也是【已截断】串 → 引擎 JSON.parse 必炸 eval_unparseable
```

问答章 cleanup 态 innerText ≈5000+ 字符 → JSON 串 5-6k > 4000。成功章恰在阈值下
（e0001 innerText 3630 字符/JSON 3730；e0002 2079/2135——**全在 4000 以下**，问答章全体越线）。
`--only 第13周问答` 干净复现：assert/题名全对，死在 `JS_INNERTEXT` 的 payload 截断。

### 根因 B：title-mismatch = enumerate TITLE_CUT 半角竖线截断 vs 页面全题

enumerate 的 `TITLE_CUT=/\s+\d+分\d+秒|\s+\d+人学过|\s+\|/` 在**半角 `|`** 处截断侧栏 li 文本 →
manifest 收「第8周问答」（裸题），而页面 article-title 渲染「第8周问答 | 人们为什么送礼而不送钱？」。
严格等值断言（switch clickAndAwait 的 `tt===want` 与 assert 的 `as.title!==a.title`）**永不等值**：
- 裸题问答章：clickAndAwait 20s 超时 → switch_failed / 断言 title-mismatch；
- 预告/加餐/复盘章在同窗口被殃及（限流时代页面停留错章 + 上游超时混合，台账里留下
  「assert 时标题=某周问答」的记录；健康环境下复测页面本身稳定不漂移——probe-dom.mjs 40s 观测）。

### 修法（engine.mjs）

1. **innerText 分片捕获**（根因 A 主修）：`JS_INNERTEXT_OPEN`（页内 `JSON.stringify` 冻结快照到
   `window.__dzItJ`，返回长度）+ `JS_INNERTEXT_SLICE(i,1900)`（按 1900 原始字符回传，再 stringify
   最坏 2× 膨胀 = 3800 < 4000）+ `captureInnerText()` 拼接后整体 `JSON.parse`（切片边界劈开转义
   序列无碍，拼接即还原）。与既有 JS_MD_SLICE 同范式（原作者已为 MD 块做过同款分片，innerText 漏了）。
   `ev()` 内保留 content_path 回读兜底（若未来 lasso 落全量数据则自动生效，零成本）。
2. **标题宽容匹配**（根因 B）：`NORM_T`（去空白 + 全角 `丨`/`｜` 统一半角 `|`）+ `titleMatches`
   = 全等 ∨ 页题 === want+`|`+剩余（竖线即侧栏截断边界）；switch（already 判定/clickAndAwait/liMatch）
   与 assert 同用一套。
3. **防错章假阳性**：cmdProduce 预计算前缀歧义（want 归一化后是**他章**标题严格前缀，如
   「加餐」vs「加餐丨大学没有围墙」）→ 该章 `allowPrefix=false` 只允许全等；liMatch 改**先精确
   （enumerate 同款 TITLE_CUT 解析 li 文本）后前缀**。11 条 titleMatches 机械用例进 selftest。
4. **innerText 捕获前幂等复隐 chrome**（JS_INNERTEXT_OPEN 镜像 JS_CLEANUP 选择器清单）：
   防侧栏文本（收起目录/设置文本）污染零丢失基准与 it1==it2 不变量。

### 复验（四类代表章全绿）

| 章 | 旧失败 | 结果 |
|---|---|---|
| 第13周问答丨城市兴衰有其内在规律 | eval_unparseable | 全绿 pages=11 promo=0（3 轮 print 收敛空洞） |
| 第8周问答（裸题/半角竖线形态） | title-mismatch 族 | 全绿 pages=12 promo=0 |
| 第1周问答丨薛老师"敲黑板"帮你划重点 | eval_unparseable | 全绿 pages=13 sikao=1/1 |
| 预告丨你的权利从哪里来？ / 预告丨认识社会成本 | title-mismatch（问答页文本）/ eval_unparseable | 全绿 pages=2 |

## 3. 模式③ — ssrf_blocked:dns_failure（104 章）

### 根因

lasso **每次** browse_logged_in 调用都跑 `ssrfGuard(url)` → `node:dns lookup('www.dedao.cn')`；
TUN 间歇故障窗口（`getaddrinfo ENOTFOUND`）内全部调用被拒（outcome=didnt，
error=`ssrf_blocked:dns_failed:…`）→ 引擎 `ev()` 抛 eval_upstream:didnt → 整章失败。
104 章连续阵亡（第081讲起一段 TUN 故障窗口）= 章级重试语义存在但**只在跨批次**生效：
单章一次抖动即烧一次 attempts。

### 修法（engine.mjs，不改网络栈）

- `browse()` 调用级瞬态重试至 **3 次**（2s/4s 退避），谓词 `TRANSIENT_RE`：
  `ssrf_blocked:dns_failed | McpError | timed out | ETIMEDOUT | ECONNRESET | fetch failed`；
  确定性失败（switch_failed/assert_failed/qc_failed/notfound/…）不重试。机械校验 5 命中 + 9 不误伤。
- 章级 `MAX_ATTEMPTS=3` 原本即 ≥3（确认项），跨批次自动重试不变。
- **观察记录（不实施）**：ssrfGuard 每调用一次 DNS 解析、无缓存——server 侧对同 host 解析结果
  做会话级缓存可整类消除该病理（lasso 侧改进项，属于 lasso 仓库；本轮不动）。TUN 环境本身见
  全局记忆 network-proxy-environment（fake-ip 劫持诊断）。

## 4. 白盒连带揪出的两个潜伏病理（修模式①时实测撞上，已同轮修复）

### 4a. 多 dedao tab 打印错位（cdpPrint 打错 tab）

- 病理：lasso 预建后台 tab + 用户 Chrome 可能开着既有 dedao tab → `cdpPrint` 旧实现
  `tabs.find(第一个 URL 匹配)` 在 >1 tab 时打印**非工作 tab**。实测：探针 tab 停在第13周问答，
  引擎处理第008讲时打出**第13周问答全文 22 页**（带未清理侧栏）→ text-loss+order+promo 三重假失败。
- 修法：`cdpPrint(out, expectTitle)` — 遍历 dedao tab 探测 `{title, foot}`（foot=引擎足迹：
  `window.__dzItJ`/`#dz-chrome-hide`，仅工作 tab 有），**足迹+标题双命中优先**（双 tab 同章时纯标题
  无法消歧，第13周问答复验时实测踩中）；打印后再校验标题，不匹配抛 `print_wrong_tab` fail fast。
- 全量首跑当年能跑通是因为全程单 tab——**用户 Chrome 开着任何 dedao tab 都会触发**，属必埋雷。

### 4b. 侧栏 React 重渲染击穿内联隐藏（cleanup display:none 失效）

- 病理：异步课程更新通知（PDF 实证出现「已更新收起目录 419 讲 / 共 408 讲」）触发 React 替换
  course-nav 节点 → 内联 `display:none` 连节点一起被换掉 → 侧栏回流打印（22 页污染 + 侧栏卡片
  带 1080×607 假 promo）。旧日志 it2 里混入「收起目录 设置文本」前缀即同源。
- 修法：JS_CLEANUP / JS_INNERTEXT_OPEN 注入 `<style id="dz-chrome-hide">`（样式表对**重渲染后的
  新节点**同样生效）；JS_SWITCH_V3 用侧栏前先摘除该样式表（display:none 容器 scrollTop 无效）。

## 5. 新增 — 批级熔断器（内建看门狗，不依赖外部监控；用户令 2026-08-19 追加）

`cmdProduce` 逐章后判定（`breakerTripReason(consecFail, cumFail, msSinceLastOk)` 纯函数）：

| 条件 | 动作 | 日志标记 |
|---|---|---|
| 连续 FAIL ≥5 章 | 暂停（state 已逐章落盘，断点续跑 `produce` 即续） | `PAUSED_BATCH_BREAKER` |
| 本批累计 FAIL >15 章 | 中止 | `ABORT_BATCH_BREAKER` |
| 20 分钟无任何 [OK] | 中止 | `ABORT_BATCH_BREAKER` |

- 停机路径与正常 BATCH DONE 同路收尾（transport.close / chrome 复隐），exit 0（台账一致、可续跑）。
- 机械校验 9 用例（4/5 连续、15/16 累计、19m59s/20m01s 停滞、优先级、正常路径不触发）全过；
  正常路径不受影响由 6 章全绿复验背书（熔断零触发）。
