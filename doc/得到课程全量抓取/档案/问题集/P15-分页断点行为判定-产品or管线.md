# P15 — 分页断点行为判定：产品侧 or 管线侧（含修复杠杆归属）

- 时间：2026-08-19（实施轮，v2 管线 extract-v2.mjs 全程白盒实证）
- 背景：用户宪法②「分页连续性——图片放不下留大片空白把图推下页」要求判定该行为归属并修复。
- 结论先行：**分页行为本身全部是产品侧（Chrome 打印引擎按 CSS 碎片化规范确定性输出），打印参数面无任何修复杠杆（P14 §2.3 已否决）；全部修复杠杆在管线侧 DOM 几何预处理 + 打印产物反馈闭环**。不构成 Chrome bug（行为符合规范语义），不报上游。

## 1. 三种断点行为的机制与归属

| # | 行为 | 机制（实测） | 归属 | 管线侧修复 |
|---|---|---|---|---|
| 1 | 图 ≤ 页高放不下剩余空间 → 整块推下页，上页留洞 | 站点 CSS `figure{break-inside:avoid}` + Chrome 块碎片化；fk p2 32.2%/l001 p1 33.3%/l002 p1 22.4% 实测 | 产品侧 | S-A 缩放（img max-height=rem-14）+ S-A' 打印反馈（本轮 3/3 章洞清零） |
| 2 | 图 > 页高（课程表 10385px）→ 锁定页边界起切片 | Chrome 把 monolithic replaced box 推到下一 fragmentainer 起切；**`break-inside:auto` + `page-break-inside:auto` 双属性 !important 实测无效**（本轮 probe + 打印复证，p4 62.4% 分毫不动） | 产品侧 | **条带化 chunk**（119×88px overflow:hidden 条带块，装箱损失 ≤88px≈8.4%<12% 门槛；PDF 侧图片对象仍单份去重 object 70） |
| 3 | 屏幕测量 ≠ 打印落位 | print media 内容宽 717px vs 屏幕 700px 重排；fk fig2 屏幕「放得下」打印被推（P14 §3 已录，本轮 it1 复现 p2 29.9%） | 产品/管线边界 | S-A' 闭环：pdfimages 实际落页 + pdftotext -bbox 洞高 → 精确缩放被推图（3/3 章一轮闭环收敛） |

## 2. 级联效应（本轮新发现，探察期未录）

缩放会使洞**向下游迁移并放大**：fk it1 p2 29.9% → 缩 fig1 → it2 p3 27.8% → 缩 fig2 → it3 p4 62.4%（撞上不可缩课程表，洞放大 2.3×）。
根因：缩放只减少总内容高，不可缩块仍锁定页边界，差额全部累积为块前页洞。
对策（已入管线）：①超页高图先条带化（消灭不可缩块）再闭环；②**保最优迭代**（Σ洞% 最小者胜出，不取最后一次打印）。

## 3. 快测洞分析器（fullness 豁免）的假阴/假阳界

- 豁免逻辑：页面有图片时按 文本跨距+图显示高+间隙 估充满度 ≥0.88 → 不判洞。校准于 PGM 墨迹 ground truth：fk p2 29.9%（bbox）vs 32.2%（墨迹），4% 线框底/墨底差（P14 §3 已录）。
- 已知假阴：图与文字交错页的真洞可能被充满度高估掩蔽（fk base p4 真洞 19.7% 被 full 1.329 掩蔽，本轮墨迹终检证实）。**出厂终检必须含 PGM 逐页墨迹**（快测只作闭环驱动）。
- 假阳：未见（图片收尾页/课程表切片页均被正确豁免）。

## 4. 遗留观察（不阻塞）

- fk 课程表条带化后 ppi 103 vs 原切片 106（条带 img 宽度取整微差），视觉无损（同一图片对象）。
- l001 一图屏幕首过缩至 120px 下限（rem=77 时下限兜底），实际打印该图由反馈轮改判（mh=283 施于另一图）；120px 图视觉抽检可接受，但「下限>剩余」时该图实际仍被推页，依赖反馈轮收敛——全量时观察此路径稳定性。
- l001 终版 p5 墨迹尾空 14.3%（v1 同类页 10-14% 量级）：图文页边正常断点，非大片空白（用户投诉样是 30%+）；快测分析器因图片充满度豁免未报——墨迹与快测的 12% 线附近分歧已知（P15 §3），全量出厂抽检以墨迹复核边界案例。
- fk p4（119 条带页）pdftoppm 单页墨迹超时（每条带绘制均全量解码 943KB jpeg，单页分钟级）——墨迹通道对该页不可用，改用 PNG 渲染+视觉模型核验（表格约 50% 高度起、底部空 5-8%、无横向断裂缝、promo 零出现）。全量产线的墨迹抽检须避开条带页或接受超时降级。

## 5. 判定汇总

- **产品 or 管线：分页行为=产品侧输出，修复=管线侧责任**。用户要求的「缩小/微调/丢图」三档全部可在管线侧机械化（丢图档本轮未触发，课程表等内容图按 P14 §3 S-D 不丢）。
- 修复配方 3/3 章洞清零、文字零丢失、宣传图零出现（见 P14 补实施结论）。

## 6. v3 轮增补（课后思考删除对分页的影响，2026-08-19）

- 删除发生在 innerText 基准与 S-A 首过**之前**（基准=删除后状态），分页闭环对缩短后的文档重新收敛：三章洞 0（l001 p1 31%→闭环一轮清零、l002 p1 19.4%→一轮清零、fk 与 v2 同轨迹 3 轮清零）。删除缩短的是文档尾部（课后思考在末段），对中部断点无放大效应——与 §2 级联效应不同源。
- 尾页留白因删除而增大（l001 p7 墨迹 70.3% vs v2 50.4%）：**末页自然尾**非病态（用户投诉样=中部推图洞，全课程 0 复发）。若未来用户要求尾页也压实，属新需求（当前宪法只约束中部连续性）。
