# P2：为什么用户已打开的日常 Chrome 不能被直接复用

## 判断：平台限制（非产品缺陷，记录结论）
1. Chrome 不带 `--remote-debugging-port` 启动则无 CDP 端口，运行中实例无法事后附加——要加必须重启浏览器
2. 即便带端口重启，Chrome 136+ **禁止对默认 profile 开调试**（安全策略；v1.8 W1-DEF-7 实证：默认 profile 启动即秒退）
3. 结论：唯一稳定路径 = 独立 profile + 一次性登录（登录态持久 ~/.cache/lasso/dedao-profile，此后免登录）——现行设计已是该限制下的最优
