# P18：章节树不完整——侧栏虚拟列表需滚动加载（用户指正）

## 现象
scout 生成的 章节树.json 只含首屏章节；实际全课程 **400+ 章**，侧栏虚拟列表远端回收、需滚动加载。

## 判断：管线缺口（非产品缺陷）+ 产品能力候选
1. 管线侧：全量引擎必须含「滚动枚举」步骤——慢滚侧栏至无新增（P7 慢滚合并法：滚动→等 DOM 稳定→合并→再滚），以最终全量树为分母。已在 章节树.json 注入 _incomplete 警示。
2. 产品候选（登记）：`browse` 增加 `scroll_until_stable` 辅助（滚动+稳定性检测合并结果）对 SPA 虚拟列表场景通用——排入升级登记表评估。

## 影响
全量预估基数从 ~113 修正为 400+（时长/体积按 3.6× 重估）；引擎断点续跑设计更重要。
