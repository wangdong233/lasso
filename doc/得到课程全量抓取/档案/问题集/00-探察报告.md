### 2.2 点击机制（实测验证）

li 无链接、无 data 属性（React 合成事件）。**用 evaluate 派发 MouseEvent 即可**：

```js
const target=[...document.querySelectorAll('div.course-nav ul.course-module>li')]
  .find(li=>(li.textContent||'').includes('第001讲'));
target.dispatchEvent(new MouseEvent('click',{bubbles:true,cancelable:true,view:window}));
// 然后在同一 evaluate 内轮询：.article-title 文本变化 → 返回新 url
```

实测：发刊词 → 第001讲 成功，URL 变为 `.../course/article?id=ml9WNdP1QvaeKYG0PJAzx82Dyog0BZ`，右栏标题同步更新（单次 evaluate 内 click+轮询 2.5s 内完成）。**判定加载完成的标志：`div.article-title` 文本换新 + `location.search` 的 id 换新**（比 wait_for 文本更稳，因标题就是子章节名）。

### 2.3 虚拟列表行为（重要约束）

- 侧栏 DOM **只渲染滚动位置附近**的章节：初始仅见 课前必读 + 01（29/110 li）；滚动后逐步展开。
- **远端章节会被回收**：慢滚一轮后 01 反而渲染满 110 li，而其余章节消失（scrollHeight 从 38606 缩到 11038）。
- **DOM 顺序不稳定**：实测「11 | 线下活动…」出现在「12｜【视频】…」之后；且存在无 header 的占位 chapter-mod（按 offsetTop 顶位）。

### 2.4 全量枚举法（给抽取阶段）

`div.ps` 慢滚动（步长 ≈ clientHeight*0.7，每步停 350ms）+ 每步快照合并：
- 快照：遍历 `div.course-nav div.chapter-mod`，取 `.chapterp-header` 文本为 key，收集其 `ul.course-module>li` 文本（按首见顺序去重）；
- 终止：连续 N 步无新章节 且 scrollHeight 稳定；
- 每章保前 3 个不同 li 标题即得「前 3 子章节」。
（参考实现：`.dedao-scout/scout6.mjs` 的 60-chapter-tree 探察；14 个主要章节全名单已录 `章节树.json`。）

## 4. PDF 抽取的工具链要点（lasso 白盒语义）

1. **单 action `pdf` 会先导航再打印**（`BrowseChannel.ts` `NAV_FIRST_ACTIONS={network,screenshot,pdf}`）→ **evaluate 清理过的 DOM 会被重导航冲掉**。
   ✅ 正确姿势：`action:"navigate"` + `options.steps:[...]` 链——链内 `executeStep` 直接 dispatch handler、**不走 NAV_FIRST**，故 `[{evaluate 清理},{pdf}]` 顺序可行（`src/channels/BrowseChannel.ts` browseSingle L311 vs executeStep L473）。
2. `pdf` 参数：A4 / printBackground 默认 true（保背景样式与图片）；Margins 默认 0.4in。base64 结果走 `applyOutputEnvelope`（>48KiB 落盘 + `read_text` ref，用 `data.bounded_output.read_text` 或 `content_path` 取回后 base64 解码存 .pdf）。
3. `evaluate` 返回经 `data.preview` 且**硬截断 4000 字符**（`PREVIEW_MAX_CHARS=4000`）→ 每个 probe 返回紧凑 JSON、分片拉取。
4. `evaluate` 的 `options.js` 是**语句体**（lasso 包成 `() => {...}`），异步逻辑要写 `return (async()=>{...})()`（裸 IIFE 会丢返回值，实测返 undefined）。
5. `wait` action 需 `options.expect.text`；对 SPA 换讲更稳的是 evaluate 内轮询 `.article-title` 文本。
6. readiness：navigate 后 `document.readyState==='complete'` 且 body innerText>800 即可用（首页 title 早期是通用「得到APP…」，勿以 title 判加载）。
7. **Chrome 生命周期红线**：lasso server 进程退出（stdin EOF）→ 停机收尾**杀 hidden 台账 Chrome**（本次实测 `chrome_stop_result action:killed tree_kill:true`）。工作流模式 = 「launch-chrome → 单 server 进程内完成全部动作 → 退出 → 下批重新 launch-chrome」；登录态在 profile 磁盘上，重启不丢（实测两轮重启后仍登录）。当前交接态：Chrome(pid 85359) 存活、**台账为空**（server 退出不会误杀），直接 `LASSO_CDP_PORT=9226` 可用。
8. 0-tab 冷启动坑：hidden Chrome（--no-startup-window）无页面时首 navigate 报 `No page selected` → 先 `curl -X PUT "http://127.0.0.1:9226/json/new?about:blank"` 开一个 tab 再连（详见问题集 P6）。
9. 图片懒加载：正文图片**无 loading 属性且实测急加载**（naturalWidth 已就绪）；保险起见打印前可 window 滚动到底再回顶（触发任何潜在懒加载 + 让长图渲染完整）。

## 5. 给抽取阶段的建议流程（每章前 3 讲）

```
launch-chrome（若 Chrome 死）→ PUT /json/new（若 0 tab）
→ 单 server 连接：
   navigate 目标页 → 轮询 ready
   → evaluate: 慢滚动侧栏枚举（§2.4）得章节×前3子章节清单
   对每个子章节：
     evaluate: 找到目标 li（按标题匹配）click + 轮询 .article-title 换新
     evaluate: DOM 清理——删 .article-cover / .dd-audio / .article-time-info 及其后兄弟
               （可选：隐藏 .iget-header / .course-nav / aside.iget-side-button / .pageControl，
                 PDF 是整页打印，不隐藏则左右栏都会进 PDF——建议隐藏左栏+顶栏只留右栏）
     evaluate: window.scrollTo 底→顶（懒加载保险）
     browse(action:"navigate"… 不行!) → 正确：browse(url, action:"navigate", options:{steps:[
        {action:"evaluate", js:<清理脚本>}, {action:"pdf"}]}) —— navigate+steps 模式下 pdf 不再重导航
→ server 退出（Chrome 若在台账会被杀；重启即恢复）
```

注意：清理+pdf 必须在同一次 browse 调用的 steps 链里完成（见 §4.1）；若分两次调用，第二次 `pdf` 的 NAV_FIRST 会重导航还原 DOM。
