# 06 质量门禁 —— 章级五门禁 + 全书六门禁 + 零丢失红线

> 红线的工程化表达：**失败不可能出厂**靠机械门禁，不靠指令遵循。实现分布在
> [脚本/engine/engine.mjs](脚本/engine/engine.mjs)（章级）与 [脚本/合并/merge.mjs](脚本/合并/merge.mjs)（全书级），判定函数在 [脚本/共享/analyze.mjs](脚本/共享/analyze.mjs) / [脚本/共享/gapfill.mjs](脚本/共享/gapfill.mjs)。

## 0. 两条用户红线（先于一切门禁）

1. **文字绝对不可丢**：每章 pdftotext vs 清理后 DOM innerText 词级/字符级 diff 必须为空——不可妥协。图可缩可删，字不可丢。
2. **尾部宣传图不进产物**：M2(1080×607 尺寸)∧M3(src 时间窗)∧M4(其后无正文)位置门控 + md5 金标裁决（全部 1080×607 候选取 md5 后与 `PROMO_MD5S` 全等才删，含非末位裸 img）。**永不全文档扫删**（防误删内容图）。

## 1. 每章五门禁（engine 自动；失败**不落产物**、state=failed 后继续下一章）

| 门 | 判定 | 失败动作 |
|---|---|---|
| ① 文字零丢失 | pdftotext vs cleanup+课后思考删除态 innerText，**字符多重集 missing 必空 + 保序（inOrder）** | 不落产物，state=failed(qc) |
| ② 宣传图零出现 | 出厂 pdfimages 无 1080×607（删前门控+md5 金标） | 同上 |
| ③ 图操作不变量 | 图删除/缩放前后 innerText **逐字节不变**（含 gap 删除档再验；视频课播放器实时时间码节点同门炸出即删） | 同上 |
| ④ 课后思考零残留 | PDF 出现次数 == 基准残留次数（正常 0/0）；删除带删前断言审计+刻意删除差机审 | 同上 |
| ⑤ MD 图片全本地化 | 下载失败进 failed 清单记 **WARN**，MD 保底远程引用（不静默丢图；终局前 backfill 补齐） | 降级 WARN |

加分项（自动）：分页 gapfill 闭环（大空缺≥35% 且次页顶有图→等比缩入下限 200css；缩后仍溢出→删图记日志；cosmetic 12-35% 只缩不删；**文字块永不动**；P30 链感知+轮次 6 严格递减）。

## 3. 读报告的正确姿势（字段语义，防误读）

### 3.1 G1 的 `missing` 是**去重字符种数**，不是丢失总量

`textZeroLoss` 返回 `missing: ["摔x5","蛇x4",…]`——**`missing.length` = 丢失的字符「种数」**（有几种字丢了），每种的实际次数在 `xN` 里。总量口径要看 `pdfChars - domChars`（返回值里的两个总数）：

- `missing.length == 0` 且 `inOrder==true` → 门过（零丢失）。
- `missing.length == 3` 不代表只丢 3 个字符——例 `["摔x5","蛇x4","…x1"]` 实丢 10 个字符、3 种。
- 反向：PDF 侧多出字符（CSS 列表序号等）是良性，不计失败。
- **missing 非空必是真阳性**：多重集+保序双 diff 下，伪影解释（提取顺序颠倒等）只影响 `inOrder`，不会无中生有 missing 字符——凡 missing 非空，先假定真丢字，逐门归因（哪章→哪个删除档→哪次操作）到底。

### 3.2 G3 的 `no_start_page` 不是噪音

连续流式版式下「随上一章同页起的章」合法地记 no_start_page——但**成规模的 no_start_page（几十条）= 缺章事故的第一声警报**（P31/P32：105 条 no_start_page 实为 105 章正文未进书）。读报告规则：

- 零星几条 + 人工核对确属同页起章 → 记录放行；
- **批量出现 → 立即查 shardNN-meta.json 的章数合计 vs plan 分母、全书 `MARKCH` 哨兵计数**——归因到底前不得交付。

### 3.3 降级语义（degraded ≠ pass）

三重全本扫描（gap 断言/洞报告/墨迹终扫）单项超时/异常**不弃报告**——如实记 `report.degradedScans[]`，对应门标注 degraded。**pass 不因降级假阳**：degraded 只表示「这一门没能完成扫描」，不表示通过；重跑 `qc` 前先按全书页数/体量校准 pdftoppm 超时。

### 3.4 `inOrder=false` 的定性方法（伪影裁决——`--adjudicate-inorder` 的唯一前置）

G1 的 `inOrder` 是子序列保序检查。书级尺度上 pdftotext 对**混排页**（同页多种对齐/栏式）会颠倒提取序，使 inOrder 假阴性——但「假阴性」必须走完失配定位才算数，不得口头定性：

1. **前提**：`missing` 多重集为空（全部字符在场，只是相对序差）。missing 非空 = 真丢字，走 §3.1 归因，与伪影无关。
2. **失配探针**：取 DOM 基准侧失配首句（diff 输出里第一处失配的连续文本），在 PDF 全文 pdftotext 输出中搜索——**存在且偏移为正**（内容完整、仅位置被提取器挪动）→ 定性提取序伪影；**找不到** → 当真丢序缺陷处理，回头查删改操作。
3. **留痕放行**：定性成立才可用 `--adjudicate-inorder` 放行该门——`report.adjudications[]` 落 `gate / verdict / evidence（探针句+偏移+missing=0 证据链）/ date`。merge.mjs 注释自引本节（「见 06-质量门禁 §3，不放水」）即指此流程。
4. 本书实例：辞典模块混排区 inOrder 失配，探针『秩序，不是由哪一个个人或者哪一个权威机构』在 PDF 全文 +20k 偏移处存在、missing=0 → 定性 pdftotext 提取序伪影（P26-③q 同族），裁决留痕后放行（示例件 [脚本/合并/merge-final-report.json](脚本/合并/merge-final-report.json) `adjudications` 字段）。

## 4. 门禁 FAIL 必须逐门归因到底（P32 铁律）

> 实战事故：终局 QC 报 G1 missing 非空 + G3 314/419（no_start_page=105），六门禁 pass=false——但被当作「罕字提取伪影 / 回填未命中的记录问题」解释后放行交付，实际是**成书缺 105 章正文**。QC 的真阳性被误判为伪影，是比缺门禁更危险的一环。

处置纪律（机械化）：

1. **任何门 FAIL → 逐门列出证据**（missing 明细/坏页清单/TOC bad 列表），逐条给出机械解释（哪个机制产生这条记录），**解释不了的就当缺陷处理**。
2. **交叉验证**：G3 异常 → 查 G1（缺章必伴随文字 missing）；G1 异常 → 查 G3/G4（丢的是整章还是字）；G4 异常 → 查删除清单（gapFill.deleted / end-imgs-dropped.json）。单门异常 + 相邻门全绿才可谈「伪影」。
3. **归因到底才放行**：每一项残余发现项要么被机械归因（如 36dpi 缩略图伪影、流式尾部空白豁免类），要么修完重跑——「如实留档」是留证据，不是免检通行证。
4. **交付阻断兜底**：全量（非冒烟）成品 report.pass=false → 自动改名 `*-QC-FAIL.pdf` 隔离 + FATAL log（merge.mjs 内建，P31 修复）——QC FAIL 的成品不得以正式名落盘被当成品取走。
5. **裁决出口（先归因，后豁免）**：归因到底后仍有「结构性豁免未覆盖的空白类残留」或「经 §3.4 定性的 inOrder 伪影」→ 用户拍板后带裁决留痕旗重跑（§4.1）——豁免是归因的出口，不是归因的替代。

### 4.1 人工豁免留痕（--waive-blanks / --adjudicate-inorder；留痕 ≠ 门禁变绿）

终局 `assemble`/`qc` 的两杆裁决旗，语义边界全部机械化，无放水通道：

| 旗 | 豁免范围 | 留痕字段 | 硬边界（不可豁免） |
|---|---|---|---|
| `--waive-blanks` | **仅空白类**：G2 `g2BlankPages`（页尾墨迹空白残留）+ `figGapPages`（图距违例） | `report.waivedBlanks`（页清单 + `authority` 裁决原文与日期） | G1 `missing`（零丢失红线）；G3/G4/promo 计数门 |
| `--adjudicate-inorder` | **仅 G1 inOrder**，且必须先完成 §3.4 失配定位定性 | `report.adjudications[]`（gate/verdict/evidence/date） | `missing=0` 是前提；missing 非空即真丢字，无任何旗可救 |

读法纪律：

- **门禁明细如实保留**：`gates.G2_pageTailBlank.fails` 等红明细不因旗消失；旗改变的只是终判 `passWithWaiver`（写入 `report.pass`）与是否触发 QC-FAIL 隔离。读报告者必须能**同时看到红明细与豁免留痕**——只看 pass 不看 waived 的是误读。
- **豁免范围隔离开**：代码层豁免仅作用于空白类与（定性后的）inOrder；终判仍要求 missingEmpty、TOC 全对、G4 计数平、promo=0 一项不落。
- **结构性豁免优先于人工豁免**：G2 结构性边界（前言/模块末页/模块界首页前页）自动进 `blankExempted`，无需旗——先重跑现版让自动集生效（本书交付版报告生成于 moduleStarts 增补之前，page 1372 尚在 `waivedBlanks` 内；现版重跑该页会落入自动豁免）。
- **新书沿用前须重裁**：merge.mjs 内 `authority`/`adjudications` 的文案是**本书裁决原文（硬编码）**——新书使用两旗前须重新走用户裁决并改写留痕文案为自己的裁决记录。
- 本书交付实例：`qc --waive-blanks --adjudicate-inorder` → pass=true（墨迹终扫常开，无 `--ink` 旗——04 §2 同口径），`waivedBlanks.g2BlankPages=[700,804,1187,1355,1372]`（authority：用户 2026-08-20「个别章节末尾空白可接受」）+ `adjudications=[G1_inOrder 辞典模块混排区伪影]`——QC-PASS 含豁免留痕的完整形态见 [脚本/合并/merge-final-report.json](脚本/合并/merge-final-report.json)。

## 5. 分片层守卫（G 门禁之前的三道闸）

1. **plan 完整性门禁**：全章 MD 齐 + 引用图全在，缺任一 FATAL 退出**不产半本**（backfill-imgs 必须在此之前跑完）。
2. **render 陈旧守卫**：片 meta 章数 ≠ 当轮 plan 章数（或 meta 缺失/损坏）→ 强制重渲——「已存在，跳过」只在章数吻合时有效。
3. **assemble 二道守卫**：拼装前同样校验，不等直接 throw——render 可跳过，assemble 不许拼「旧片+新 plan」。

## 6. 视觉抽检（慢通道，批后抽样）

- **两段式替代法**（P12：无视觉呈现通道时的机械化校验）：pdftoppm 渲 PNG + VLM 问询 + 页级 md5 对比。
- `merge.mjs sample --pages …` 抽查页选取：封面/目录/各模块首章/随机/末页。
- 条带化页（超页高图）pdftoppm 分钟级超时属预期——跳该页改 PNG 核验（P15 §4）。
- QC 报「+order」失配先验视觉/DOM 谁是权威（印刷品=视觉序），再查提取器伪影（pdftotext 同页混排对齐会颠倒提取序——排版统一 `text-align:left` 是正字也是解法），最后才动内容。

## 7. 人工纪律（执行代理红线）

- 单 Chrome 全程隐藏；≤2 个 engine worker（只经 run-k2.mjs）；0 个并发 merge 渲染（merge 与 produce 不并行；render/assemble/qc 串行）。
- 删图只能走 gapfill big 档规则（日志留痕）；任何「为了排版删文字」的操作一律禁止。
- 任何问题两次纠错失败 → 停，记 [档案/问题集/](档案/问题集/README.md) 新 P 条目，换路径重述；不第三盲试。
