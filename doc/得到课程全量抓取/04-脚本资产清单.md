## 2. CLI 参数速查

### engine.mjs

```
node engine.mjs enumerate                      # 侧栏慢滚合并 → manifest.json（全量分母）
node engine.mjs produce [--only a,b] [--limit N] [--retry] [--force]
node engine.mjs produce --worker k/K           # 由 run-k2 注入，勿手跑（日志前缀/独立文件/jitter/SPA 复位 25→15）
node engine.mjs status                         # 进度/均值/ETA/失败清单（只读）
node engine.mjs selftest                       # 内嵌 JS 片段语法闸 + titleMatches（改完必过）
```

### run-k2.mjs

```
node run-k2.mjs                          # 全量：两 worker 按 manifest.idx 奇偶分片
node run-k2.mjs --only "标题A,标题B,…"    # 指定章 round-robin 均分
# 透传 --retry / --force；启动自动清 BREAKER.trip
```

### backfill-imgs.mjs

```
node backfill-imgs.mjs    # 无参数；读 manifest，扫 MD 引用，反推 piccdn3.umiwi.com/img/YYYY/MM/NAME 下载
```

### merge.mjs

```
node merge.mjs plan                              # 完整性门禁（缺 MD/缺图 FATAL，不产半本）
node merge.mjs render [--module K] [--force]     # 分片渲染（陈旧守卫：片 meta 章数≠plan 强制重渲）
node merge.mjs assemble [--partial]              # TOC 两遍回填+pypdf 合并+页码+书签+六门禁+墨迹终扫
node merge.mjs qc [--pdf <path>]                 # 独立复核（不重渲染）
node merge.mjs sample --pages 1,2,3 [--pdf p]    # 抽查页 PNG
node merge.mjs all                               # plan→render→assemble 一键（建议分步）
# 冒烟三件套（不落正式分片名）：--partial / --titles <file> / --tag-suffix <s> / --out-name <name>
# 压缩阶梯②开关：--keep-end-imgs（对照实验用；默认开 end-img-drop；豁免模块走 config.END_IMG_KEEP_MODULES）
# 裁决留痕两旗（assemble/qc；语义红线见 06-质量门禁.md §4——先逐门归因，后豁免；留痕≠门禁变绿）：
node merge.mjs qc --waive-blanks                 #   G2 空白类残留（g2Blank/figGap）人工豁免 → report.waivedBlanks（含 authority）
node merge.mjs qc --adjudicate-inorder           #   inOrder 经 06 §3.4 失配定位定性为提取序伪影后放行 → report.adjudications
#   （G1 missing 零丢失红线两旗都不可豁免；本书交付实跑：qc --waive-blanks --adjudicate-inorder）
```

### probe 探察件 / 自测件 / 收尾件（engine 组）

```
node probe-figs.mjs "<章标题>"            # 该章全部 figure：nat 尺寸 + md5 前12位(字节数) + caption + src 文件名
                                          #   —— PROMO_MD5S 采样主工具：尾部 nat=1080x607 即 promo 候选，
                                          #      全量 md5 用 curl -s "<图完整URL>" | md5 取（probe 只打前 12 位）
node probe-dom.mjs ["<章标题>"] [--watch 30]  # 页面/DOM 结构 dump（SIKAO 锚与栏目边界白盒——07 步骤 4）
node probe-struct.mjs                     # wrap 子结构 4 层 dump（评论区/笔记区边界）
node probe-li.mjs                         # 侧栏 li 属性（articleId）
node probe-notes.mjs                      # 「笔记」类尾部 UI 定位
node probe-chips.mjs                      # 双 term chip 结构（零 timer 切换验证）
node selftest-gapfill.mjs                 # P30 gapfill 升级回归自测（A-F 断言组；只读既有产物，任意 cwd）
node sweep-tail.mjs                       # 失败章小批重启收尾（P26；头部路径/章集为本书值，换书须改）
./watch-flicker.sh                        # Chrome visible 翻转观察器（P27；300ms 轮询是负载源，用完即撤）
# 附着规则：各 probe 优先附着既有 dedao 课程 tab；无 tab 时 probe-figs/probe-dom 按头部
# TARGET_URL 导航——该 URL 为本书课程地址（未走 config.mjs），换书须同步改头部。
```

### img-opt.mjs

```
node img-opt.mjs <图片路径> [maxDim=1400] [quality=78]   # CLI 自检：打印前后体积
```

## 3. 依赖关系图

```
                 ┌──────────────── 外部系统 ────────────────┐
                 │  lasso MCP server（LASSO_ROOT/dist/index.js）│
                 │  专用隐藏 Chrome（CDP 127.0.0.1:9226）        │
                 │  poppler 四件套：pdftotext/pdfimages/         │
                 │    pdfinfo/pdftoppm                          │
                 │  macOS sips（img-opt 用）                    │
                 │  pypdf venv（VENV_PY，PEP 668 禁系统装）      │
                 │  piccdn3.umiwi.com（backfill 补图下载）       │
                 └──────┬──────────┬──────────┬────────┬──────┘
                        │          │          │        │
   engine.mjs ──────────┘          │          │        │  （经 stdio spawn lasso server；
   ├─ config.mjs（./ 相对）         │          │        │    node_modules 符号链接→lasso/node_modules）
   ├─ 共享/{analyze,gapfill}.mjs ──┤          │        │
   │    （头部绝对 import）          │          │        │
   ├─ manifest.json / state.json（读写）      │        │
   └─ scratch/ 证据 + logs/                  │        │
                                             │        │
   run-k2.mjs ─ spawn 2× engine.mjs produce --worker；读写 BREAKER.trip
   backfill-imgs.mjs ─ config.mjs + manifest.json ──────────┤
                                             │        │    │（fetch CDN）
   merge.mjs ───────────────────────────────┼────────┘    │
   ├─ config.mjs（./ 相对）                  │（CDP 渲染）
   ├─ 共享/{analyze,gapfill}.mjs（绝对 import）│
   ├─ manifest.json / state.json（只读）      │
   ├─ merge-assemble.py（execFileSync VENV_PY）─ pypdf
   ├─ <OUT_DIR>/.work/ 中间件 + shardNN 产物 + meta.json
   └─ img-opt.mjs（影子目录；渲染期可选接入）

   merge-assemble.py ─ pypdf（venv；输入 assemble-spec.json，输出成品+页数/书签统计 JSON）
   img-opt.mjs ─ sips（无 ImageMagick 依赖；影子目录可经 IMG_OPT_DIR 指定）
```

要点：

1. **engine.mjs 依赖 lasso server**：MCP stdio 子进程（`@modelcontextprotocol/sdk`，经 `node_modules → lasso/node_modules` 符号链接复用依赖）+ 直连 CDP `Page.printToPDF`。
2. **engine.mjs / merge.mjs 都依赖共享两件**：头部以绝对路径 import `lasso/.dedao-extract/{analyze,gapfill}.mjs`——**单一规则权威**，禁两套漂移（缩图/删图裁决、洞检测、零丢失 diff 全部同源）。
3. **merge.mjs 依赖三样**：共享两件 + `merge-assemble.py`（经 config `VENV_PY` 的 venv python 执行）+ 隐藏 Chrome（分片 printToPDF 渲染）。render/assemble/qc 串行，**与 produce 不并行**。

## 4. 数据流与台账

```
enumerate → manifest.json（分母：模块+子章节有序清单，idx 严格单调）
produce   → 每章 <模块dir>/<title>.{pdf,md} + <模块dir>/images/
          + state.json（每章原子写：done|failed|pending/attempts/fatal/sha256/QC 摘要）
          + scratch/<章>.*.json（取证证据）
backfill  → 补齐 images/；MD 远程引用改本地（手工）
plan      → merge-plan.json（shards/expectedImgs/missingImgs——缺即 FATAL）
render    → shardNN-<模块>.pdf + shardNN-meta.json（pages/chapters/flowChapters/gapFill/figs）
assemble  → 前言两遍 → .work/page-numbers.pdf（overlay）→ assemble-spec.json
          → 成品 PDF + merge-final-report.json（六门禁+删图/缩图清单）
          → end-imgs-dropped.json（阶梯②删除清单）
qc/sample → 只读复核/抽查 PNG
```

## 6. 还原到可运行布局（换书部署）

收录件按「engine / 合并 / 共享」三组存放是为查阅清晰；**运行时它们分属两个目录**：

```bash
# ⓪ 前置（本目录无法提供，须先行就位——2026-08-20 演练确认）：
#    lasso 仓库本体（git clone + npm install + 构建出 dist/index.js）——engine 以它为 cwd spawn
#    `node dist/index.js`，③ 又链它的 node_modules；② 的真实语义=把共享两件【刷入】该仓库
#    外部工具：poppler 四件套 / macOS sips / 网络（pip 装 pypdf）
# ① 引擎目录：engine 组 + 合并组 两目录的全部文件，平铺拷入新课程 .engine/
mkdir -p "<新课程目录>/.engine"
cp 脚本/engine/{config.mjs,engine.mjs,run-k2.mjs,backfill-imgs.mjs} "<新课程目录>/.engine/"
cp 脚本/合并/{merge.mjs,merge-assemble.py,img-opt.mjs}       "<新课程目录>/.engine/"
#    （RUNBOOK.md / manifest.json / merge-final-report.json / end-imgs-dropped.json 是文档与示例，
#      不参与运行；probe-*.mjs / selftest-gapfill.mjs / sweep-tail.mjs 为探察/自测/收尾件——
#      换书适配（07 步骤 4）要用 probe-dom/probe-figs，建议一并拷入并改其头部本书常量）

# ② 共享组：刷入 lasso 仓库的 .dedao-extract/（engine.mjs/merge.mjs 头部绝对 import 指向这里）
cp 脚本/共享/{analyze.mjs,gapfill.mjs} "<lasso 仓库>/.dedao-extract/"

# ③ 依赖符号链接（复用 lasso 的 node_modules，MCP SDK）
ln -s "<lasso 仓库>/node_modules" "<新课程目录>/.engine/node_modules"

# ④ pypdf venv（PEP 668 禁系统安装）
python3 -m venv <某处>/.venv && <某处>/.venv/bin/pip install pypdf

# ⑤ 改 config.mjs（lasso 在 canonical 路径时的唯一必改文件；换本课的
#    COURSE_NAME / COURSE_DIR / TARGET / VENV_PY 四值）
# ⑥ 台账必须干净（enumerate 会直接覆写 manifest/state——F1 教训）：
#    <新课程目录>/.engine/{state.json, manifest.json, scratch/, logs/}
#    <新课程目录>/.production-state.json   ← 在课程根，不在 .engine/（engine.mjs: path.join(BASE,…)）
```

相对 import 关系说明：`run-k2.mjs`/`backfill-imgs.mjs`/`merge.mjs` 均以 `./config.mjs` 相对引用配置——**四件必须在同一目录**（即 ① 的平铺）；`engine.mjs`/`merge.mjs` 对共享件用绝对路径 import——路径落在 ② 的位置即免改。

**若把 lasso 放在别处，完整改动清单（4 个位置、5 行，缺一即断）**：engine.mjs 头部 2 条 import + merge.mjs 头部 2 条 import + config.mjs `LASSO_ROOT`（engine 的 spawn cwd）+ ③ 符号链接目标。只改「两条 import」不够。

**成对同步警示**：`merge.mjs` 与 `config.mjs` 必须同批同步（merge 读 `CFG.END_IMG_KEEP_MODULES`，且 config 防呆断言要求该键非空数组）——只更新 merge.mjs 不更新 config.mjs 时旧 config 缺键会静默回退空数组（无豁免），反之日后单独换 config 也须确认与 merge 版本配套。收录件两者均为 2026-08-20 12:3x 实战终态，成对有效。

**干净台账下的预期报错形态（fail-fast，不是还原失败）**：
- `node engine.mjs status` → 正常打印 `manifest: 未生成（先 enumerate）`；`selftest` → `selftest OK (16 fragments + 11 titleMatches)`
- `node merge.mjs <任何子命令>` / `node backfill-imgs.mjs` → 模块加载刻 ENOENT 崩（读 `<课程>/.engine/manifest.json`，merge.mjs:42）——先跑 `engine.mjs enumerate` 产出分母
- `node run-k2.mjs` → 启动即删 BREAKER.trip 并 spawn 两 worker，**非无副作用**，勿当自检跑
