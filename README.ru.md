## 💰 Стоимость кратко

Сам Lasso **полностью бесплатен + MIT open source**. Вот во сколько реально обходится каждая возможность:

| Возможность | Стоимость | Примечания |
|---|---|---|
| Сам Lasso (MCP-сервер + все основные возможности) | ✅ Бесплатно | MIT open source, бесплатно навсегда |
| Поиск (переиспользование машинного MCP Zhipu + Brave) | ✅ Обычно без настройки | Если на машине уже настроен MCP `web-search-prime` от Zhipu, Lasso переиспользует его автоматически (основной путь — вообще без ключа поиска); Brave — опциональный платный план с \$5/мес кредита (бесплатный тариф отменён с 2026-02); у Lasso есть и собственный бесплатный фолбэк живого поиска — поиск работает, даже если ничего не настраивать. С v1.17 Lasso больше не поддерживает собственный прямой ключ Zhipu (`ZHIPU_API_KEY` выведен из эксплуатации) |
| Скрейпинг публичных страниц / скриншоты / PDF / аудит сети / сырые байты / локальный приватный поиск (v1.17: история+файлы) | ✅ Бесплатно | Работает локально, без ключа, без оплаты |
| Скрейпинг залогиненных страниц (переиспользование локального Chrome) | ✅ Бесплатно | Работает локально, без ключа, без оплаты |
| Управление рабочим столом (macOS / Windows / Linux) | ✅ Бесплатно | Сборка и запуск локально, нужна только авторизация ОС; **опционально** Apple Developer account \$99/год для подписанной постоянной авторизации (работает и без подписи — просто повторно авторизуйтесь каждый раз) |
| Облачный браузер · self-hosted Steel (новое в v1.6) | ✅ Бесплатно | Steel (Apache-2.0 open source) в локальном Docker — **ноль стоимости за сессию + куки не покидают вашу машину**; нужны `LASSO_ALLOW_CLOUD_BROWSER=true` + `STEEL_ENDPOINT=http://localhost:3000` |
| Облачный браузер · hosted (browserbase / stagehand) | ⚠️ Платно, по умолчанию выключено | browserbase — оплата по факту после триала; stagehand — программный экспериментальный канал (без MCP-инструментов); **не настроите — не заплатите ничего** |
| Анти-детект `browse_headless` (новое в v1.5) | ✅ Бесплатно | По умолчанию вживляется 16 слоёв анти-детекта (UA / webdriver / webgl и т. д.) — проходит многие базовые проверки на бота |

> Одной фразой: **пока вы не включите hosted-облачный браузер (browserbase / stagehand), Lasso стоит ноль** — у поиска достаточно бесплатных лимитов на каждый день, а self-hosted Steel тоже бесплатен.

## Старт за 60 секунд

### 30 секунд · Установка в одну строку (нулевая конфигурация)

```bash
claude mcp add lasso -- npx -y lasso-mcp
```

Перезапустите Claude Code → введите `/mcp` → увидите `lasso ✓ Connected`. Готово. **В команде установки нет никаких ключей** — настройка идёт отдельным шагом (следующий уровень).

### 30 секунд · Без всякой настройки уже можно делать всё это

Сразу после установки ключи не нужны (это **Уровень 1: нулевая конфигурация**):

- Собрать текст любой **публичной веб-страницы** с конвертацией в чистый markdown
- **Полностраничные скриншоты** и **сохранение в PDF** с возвратом пути к файлу
- Посмотреть, **какие сторонние трекеры загружает страница**
- Забрать сырые байты напрямую из JSON API или файла
- Управлять нативными приложениями macOS (Finder / Mail / «Системные настройки» и т. п. — нужен разовый клик в «Системных настройках»)

> 💡 **Поиск по умолчанию работает без настройки**: если в `~/.claude.json` на вашей машине уже настроен MCP `web-search-prime` от Zhipu, Lasso при старте автоматически его обнаруживает и переиспользует — поиск просто работает, вообще без ключа поиска (с v1.17 это единственный поддерживаемый способ использовать Zhipu). Запустите `lasso doctor` и проверьте, что `#36 machine_search_mcp` в статусе `pass`.

Ваш первый результат — просто скажите Claude:

> «Собери текст с example.com и преврати его в markdown»

### Хотите большего? Добавьте в файл конфигурации (Уровень 2)

- **Поиск** → обычно без настройки (переиспользование машинного MCP Zhipu); при желании добавьте ключ Brave как второй источник (см. [Настройка](#настройка))
- **Скрейпинг залогиненных страниц** (Jira / приватный GitHub / корпоративный интранет) → один раз выполните `lasso launch-chrome`
- **Управление рабочим столом macOS** → один раз выполните `lasso doctor`, чтобы пройти авторизацию подсказками

Как получить каждый ключ и какие есть бесплатные лимиты — см. [**Руководство по настройке ключей**](./doc/KEY-GUIDE.md).

## Что он может для вас сделать

Сгруппировано по **тому, что вы хотите сделать**, а не по названию инструмента. Каждое — одна фраза на вход, одна на выход.

### Поиск

> Вы: «Найди X» → структурированные результаты поиска

По умолчанию переиспользуется машинный MCP Zhipu (силен для китайского, без настройки); в качестве второго источника можно дополнительно настроить Brave (мёртвые слои Bing и прямой Zhipu удалены — оставшиеся ключи конфигурации терпятся, но молча игнорируются). **Если один источник упёрся в лимит или недоступен — автоматически переключается на следующий, вы ничего не замечаете.** Исчерпание бесплатной квоты у одного провайдера не ломает всю систему.

Для **свежих** материалов — новостей, движения версий — просто скажите «найди X за последнюю неделю / последний месяц»: фильтр свежести применяется автоматически (day / week / month / year, v1.11), без рукописных дат в запросе.

> Хотите **тексты страниц вместе с результатами**? Скажите «найди и приложи 3 блока текста» (`content_blocks: 1-5`, v1.17) — после ссылок Lasso параллельно забирает топ-N страниц и обрезает каждый текст до ~6k символов **по вашему запросу** (лид-абзац сохраняется всегда, ключевые секции первыми): один шаг до «ссылки + сразу читаемый текст». Недоступные позиции **честно помечаются** (`fetch_failed` / `not_html`), ссылка остаётся — worth ли запускать браузер, решаете вы (или ИИ). Ноль платных зависимостей, браузер не запускается.

### Поиск по вашей собственной машине (новое в v1.17)

> Вы: «какие страницы про X я читал недавно?» / «какие локальные файлы упоминают X?» → локальный приватный поиск

`search_local` опрашивает **историю Chrome** (все профили) и **файловый индекс Spotlight** (mdfind) прямо на вашей машине — без сети и облака. Приватность встроена: **возвращаются только заголовок / URL / время / совпадающий фрагмент заголовка, никогда полный экспорт содержимого страниц**, максимум 50 результатов, исходные базы открываются только на чтение. Полнотекстовый поиск Apple Notes пока не открыт (честное «ещё не реализовано» вместо имитации поиска).

### Скрейпинг публичных страниц (без логина)

> Вы: «Собери текст с example.com» → чистый текст статьи, три уровня детализации

Автоматически удаляет панели навигации, рекламу, сайдбары и прочий мусор — **экономит 30–70% токенов** (и денег). GitHub / Reddit / Hacker News / Wikipedia / Substack / Medium и ещё **более 20 часто посещаемых сайтов идут через выделенные экстракторы**, таблицы и формулы не теряют структуру (v1.12) — ссылки в тексте становятся полными абсолютными адресами. Нужны маркеры цитирования (отлично подходит для исследований, для подачи в RAG)? Одна фраза переключает режим.

> Хотите **продолжить взаимодействие сразу после чтения** (нажать кнопку, заполнить форму)? Скажите «добавь интерактивные дескрипторы в извлечение» (`include_refs`, v1.17) — в конец markdown добавляется таблица дескрипторов вида `[r1] button "Отправить"` (сам текст остаётся без меток), после чего «кликни r1» / «заполни r2 значением X» находит элемент прямо по дескриптору, без повторного снапшота всей страницы. Если страница изменилась, дескриптор **честно устаревает** (возвращает didnt и предлагает переизвлечь — без угадываний и автоповторов).

> **С v1.5 у `browse_headless` анти-детект включён по умолчанию** (подменённый UA / вычищенный `navigator.webdriver` / поддельные webgl, plugins, codecs — больше десятка слоёв). **Без настройки — работает само.** Многие сайты-«детекторы headless» теперь парсятся напрямую (v1.8 исправила дефект, из-за которого вживление молча не срабатывало — теперь оно реально работает, а его сбой честно пишется в лог). С v1.11 анти-детект действует **уже на уровне запуска браузера**: UA, вьюпорт и язык спускаются единым профилем — HTTP-заголовок сетевого уровня и JS страницы видят одни и те же значения, противоречий больше нет; с v1.12 на macOS отпечаток по умолчанию **совпадает с вашей системой** (кончилось «UA говорит Windows, а характеристики машины выдают macOS»). Только тяжёлый анти-бот уровня Cloudflare требует облачного браузера (см. «Обход анти-бота» ниже). Хотите проверить анти-детект? Запустите `lasso doctor --stealth-check` — сравнение на детекционной странице creepjs.

### Скрейпинг залогиненных страниц (даже с 2FA)

> Вы: «Покажи мои задачи в Jira» → снимок залогиненной страницы

Переиспользует **ваш локально залогиненный Chrome** — 2FA вы проходите один раз; дальше Lasso берёт всё на себя. Работает для приватных репозиториев GitHub, корпоративных интранетов, платного контента по подписке и т. д.

> 🔴 **Красная линия**: Lasso **никогда не решает за вас 2FA / SMS-коды / CAPTCHA / magic links**. Вы обязаны один раз вручную пройти их в своём локальном Chrome.

> 🛡️ **Подтверждение высокорискованных действий внутри раунда** (v1.17): когда автоматическое действие попадает на высокорискованный паттерн (редакторы rich text, drag-and-drop, временные тосты…), клиенты с поддержкой elicitation (Claude Code ≥ 2.1.76) получают вопрос в том же раунде — «продолжить / пропустить / прервать» — и шаг выполняется только при «продолжить», вместо прерывания всего запуска. Старые клиенты сохраняют текущее поведение без изменений (безопасная блокировка). **Подтверждение действует только на конкретное попадание**: каждый раз спросят заново; ничего не запоминается.

### Получение сырых байтов (быстрее всего и дешевле всего)

> Вы: «Сделай GET этого JSON endpoint» → сырые байты

Когда не нужно рендерить всю страницу, прямой HTTP **примерно в 4 раза быстрее и в 4 раза дешевле**, чем через браузер. Автоматически определяет тип контента (JSON / текст / бинарник).

### Скриншот / Архив

> Вы: «Сделай скриншот всей страницы» / «Сохрани в PDF» → путь к файлу на диске

Все изображения и PDF **сохраняются на диск и возвращается путь** — никакой гигантский блоб не сваливается в чат и не тратит контекст. Очень большие текстовые выводы (fetch_url / network и т. п.) свыше 48 KiB тоже автоматически уходят на диск, возвращая превью + хэндл постраничного чтения `@oN` — дочитывайте постранично инструментом `read_text` (с v1.8 доступен напрямую через MCP).

### Что загружает страница

> Вы: «Какие сторонние трекеры загрузила эта страница?» → список ресурсов с подсчётом по доменам трекеров

Автоматически определяет все ресурсы, которые грузит страница, и группирует их по сторонним доменам — удобно для оценки рисков приватности и узких мест производительности. С v1.11 сбор ресурсов идёт напрямую через нативный сетевой слой браузерного движка — **полный даже в окружении с прокси / TUN-сетью**, и у каждого ресурса есть метод запроса и код статуса.

### Управление нативными приложениями рабочего стола

> Вы: «Выключи тёмную тему» / «Прочитай первый элемент во входящих Mail» → автоматическое действие (с проверкой)

На macOS можно управлять Finder / Mail / Safari / Notes / «Системными настройками» и любым нативным приложением. **Windows и Linux тоже работают** (см. честную границу ниже). Каждое действие проверяется — подтверждается «это действительно произошло», успех никогда не подделывается.

> **Честная граница**: macOS проверен на реальном железе; Windows / Linux проходят проверки на этапе компиляции и на уровне контрактов, но полное ручное тестирование на реальных машинах ещё в работе. **Мы не выдаём желаемое за действительное про «полностью проверено на Win/Linux».**

### Единое планирование между вебом и рабочим столом

> Вы: «Покажи всё, чем я сейчас могу управлять» → единый список

Веб-страницы и окна рабочего стола находятся в одном списке — не нужно различать «это в браузере» и «это на рабочем столе». Claude выбирает, с чем работать, и всё идёт оттуда.

### Оживление мёртвых ссылок

> Вы: «Эта ссылка 404» → самый свежий снимок Internet Archive

Идёт в Internet Archive (Wayback Machine), чтобы найти последнюю заархивированную копию этого URL. **Никогда не считает живую ссылку мёртвой** — ищет только когда вы говорите «этого больше нет».

### Обход анти-бота (по умолчанию выключено)

> Вы: «Тут Cloudflare, не могу спарсить» → анти-бот через облачный Chrome

**Полностью выключено по умолчанию.** Активируется только когда вы явно его включаете И настроили облачный браузер (self-hosted Steel или hosted browserbase / stagehand). Лёгкий анти-бот уже проходится встроенным анти-детектом `browse_headless` — **только защита уровня Cloudflare требует облачного браузера**.

- **Self-hosted Steel (рекомендуется · бесплатно)**: опенсорсный облачный браузер в локальном Docker — ноль стоимости за сессию, куки не покидают машину. Одна команда для запуска, см. [Руководство по ключам · Steel](./doc/KEY-GUIDE.md#steel_endpoint--自托管云浏览器v16-新推荐免费).
- **browserbase (hosted · платно)**: оплата по факту после триала — запасной вариант, если не хочется самому возиться с Docker.
- **stagehand (hosted · платно)**: ⚠️ программный экспериментальный канал — настройка ключа лишь собирает внутренний канал, **MCP-инструментов нет** (REST-контракт не проверен; `lasso doctor` #39 `stagehand_rest_contract_probe` проверяет именно это).

## Настройка

**Только поиску нужен ключ — всё остальное работает сразу после установки.** Сверьтесь по таблице:

| Что вы хотите | Что настроить |
|---|---|
| Скрейпинг публичных страниц / скриншоты / PDF / просмотр трекеров / сырые байты / управление рабочим столом | **Вообще ничего** |
| Поиск | Обычно без настройки (переиспользование машинного MCP Zhipu); опциональный ключ Brave (платный план) |
| Поиск почти без сбоев | Добавить ключ Brave (платный план с \$5/мес кредита; и без него есть бесплатный фолбэк живого поиска) |
| Скрейпинг залогиненных страниц | Один раз выполнить `lasso launch-chrome` |
| Управление рабочим столом macOS | Один раз выполнить `lasso doctor` для авторизации |
| Скрейпинг сайтов под Cloudflare | Главный переключатель + Steel (self-hosted бесплатно) / browserbase (платно) |

Ниже каждый из четырёх модулей с настройкой «минимум, чтобы заработало»; детали — в свёрнутых блоках.

### 1. Поиск (✅ Бесплатно · единственный модуль, где нужен ключ)

**Сначала проверьте, нужна ли настройка**: если на машине уже настроен MCP `web-search-prime` от Zhipu, **Lasso автоматически обнаруживает и переиспользует его ключ** — вписывать ничего не нужно. Запустите `lasso doctor`: `#36 machine_search_mcp` в состоянии `pass` — это как раз ваш случай.

**Если настраивать — три шага**:

```bash
lasso config init        # создаёт ~/.lasso/config.json
```

```json
{ "ZHIPU_API_KEY": "your_zhipu_key" }
```

Сохранили — работает. **Хотите надёжнее**: добавьте ещё Brave (платный план с \$5/мес кредита ≈ 1000 запросов, нужна банковская карта — бесплатный тариф отменён с 2026-02; если настроенный провайдер падает — автоматическое переключение на следующий; несколько ключей через запятую, у каждого своя квота):

```json
{
  "ZHIPU_API_KEY": "your_zhipu_key",
  "BRAVE_API_KEYS": "bravekey1,bravekey2"
}
```

> Порядок фолбэка: переиспользование машинного MCP → Brave (если задан ключ) → фолбэк живого поиска в headless-браузере (v1.14: английский фолбэк на двух движках — при провале/пустоте DDG автоматически даётся одна повторная попытка через живой поиск Brave; v1.15 добавляет перед ним **быстрый HTTP-зонд без браузера** (~1с, страница результатов забирается вовсе без браузера — в реальных тестах некоторые движки меньше подозревают клиентов без браузера); только если он ничего не нашёл, стартует медленный headless-путь). Первый сбой — автоматический переход к следующему. (Источник Bing удалён целиком после вывода апстрима 2025-08-11, а прямой ярус Zhipu удалён в v1.17; оставшиеся `BING_API_KEYS` / `ZHIPU_API_KEY` молча игнорируются, `lasso doctor` предложит их убрать.)

Как оформлять ключи, размеры бесплатных лимитов → [Руководство по настройке ключей · Поиск](./doc/KEY-GUIDE.md#a-搜索). Частые команды: `lasso --version` / `lasso --help` (с v1.8 неизвестная команда печатает usage и выходит с ненулевым кодом — больше не висит молча).

### 2. Скрейпинг залогиненных страниц (✅ Бесплатно · одна команда, без ключа)

```bash
lasso launch-chrome
```

Первый раз войдите в свои аккаунты в этом окне (2FA — сами), **логин дальше переиспользуется постоянно**. Затем просто скажите Claude «открой мой залогиненный Jira».

- По умолчанию работает **молча, без окна**, не крадёт фокус, всегда беззвучен; хотите понаблюдать — добавьте `--mode visible`
- **Закрывается сам через ~60 с после использования** — не нужно ничего запоминать; закрыть вручную можно всегда: `lasso chrome-stop`
- Вкладки, которые он открывает в вашем Chrome: после задачи скажите `admin {action:"tab_restore", reason:"готово"}` — исходный список восстановится (то же самое происходит автоматически при выходе сервера)

> 🔴 **Красная линия**: 2FA / коды / CAPTCHA — Lasso не решает их за вас; пройдите их вручную один раз в окне.

<details>
<summary>Подробнее: переиспользование профиля / занятый порт / параметры / граница тишины</summary>

- С v1.8 по умолчанию используется отдельный профиль Lasso (Chrome 136+ запрещает отладочный порт на профиле по умолчанию — старый способ закрывался мгновенно); переиспользовать существующий каталог: `lasso launch-chrome --profile <каталог>`.
- После запуска отладочный порт автоматически проверяется: Chrome не поднялся / порт занят → явная ошибка, без ложного успеха.
- Порог авто-закрытия: `LASSO_LAUNCH_IDLE_MS` (по умолчанию 60000; `300000` — обратно 5 минут; `0` — отключить). Разовое длинное задание: `--idle-ms 3600000`.
- Headless-браузер авто-утилизируется после 5 минут бездействия (`LASSO_HEADLESS_IDLE_MS` настраивается / отключается).
- Честная граница: одиночный запуск `lasso launch-chrome` (без сервера) не имеет idle-автозакрытия — выход по-прежнему `chrome-stop`; `browse_logged_in`, подключённый к **вашему собственному видимому Chrome**, — «малозаметно, но не ноль помех» (ограничение платформы macOS — отдельные действия могут один раз перехватить фокус) — для полной тишины используйте скрытый режим или `browse_headless`; канал `desktop` эмулирует живые клавиатуру и мышь, по задумке занимает физические клавиатуру и мышь — молчаливой формы нет.
- chrome-stop закрывает только Chromes, запущенные самим Lasso, с проверкой владельца — ваши вручную открытые браузеры не пострадают.

</details>

### 3. Управление рабочим столом (✅ Бесплатно · разовая авторизация, без ключа)

- **macOS**: выполните `lasso doctor` и по подсказкам отметьте `lasso-rust-helper` в разделах **Универсальный доступ** + **Запись экрана**

**Подробнее** → [Руководство по настройке ключей · Управление рабочим столом](./doc/KEY-GUIDE.md#c-桌面控制系统授权无-key).

### 4. Облачный браузер (по умолчанию выключен · нужен только для тяжёлого анти-бота)

Лёгкий анти-бот уже проходится встроенным анти-детектом `browse_headless` — **если не нужно, не настраивайте**. Чтобы пробить анти-бот уровня Cloudflare, одновременно нужны главный переключатель и один канал:

```json
{
  "LASSO_ALLOW_CLOUD_BROWSER": true,
  "STEEL_ENDPOINT": "http://localhost:3000"
}
```

- **Self-hosted Steel (рекомендуется · бесплатно)**: поднимается одной Docker-командой `docker run -p 3000:3000 -p 9223:9223 ghcr.io/steel-dev/steel-browser` — ноль за сессию, куки не покидают машину
- **browserbase hosted (платно)**: замените на `"BROWSERBASE_API_KEY": "your_key"` — вариант без возни с Docker
- ⚠️ stagehand: программный экспериментальный канал, без MCP-инструментов — не рассчитывайте на него для скрейпинга страниц

**Как оформить ключи, полные шаги подъёма Steel** → [Руководство по настройке ключей · Облачный браузер](./doc/KEY-GUIDE.md#d-云浏览器反爬默认关双重解锁)。

## Конфиденциальность и безопасность

Ваши данные принадлежат вам.

- **Login-куки никогда не экспортируются**, если только вы явно не согласились и не зашифровали их на диск. Lasso никогда втайне никуда не отправляет ваше залогиненное состояние.
- **Логи действий на рабочем столе хранятся локально** — ноль удалённой отчётности. Lasso не «звонит домой» о том, что вы делаете.
- **Облачный браузер по умолчанию выключен** — для активации нужно ваше **явное двойное подтверждение** (главный переключатель + ключ). Без него возможность фактически не существует.
- **Никакого решения 2FA / CAPTCHA / кодов подтверждения** (красная линия). Они всегда требуют, чтобы вы лично один раз прошли их в своём локальном браузере.
- **Посторонние не могут дотянуться до ваших внутренних сервисов** — доступ к внутренней сети по умолчанию запрещён; TUN-прокси-сети Surge / Clash уже разрешены из коробки без дополнительной настройки.
- **Результаты поиска по умолчанию не пишутся на диск** — только если вы явно включите режим записи (для регрессионного тестирования).

## Устранение неполадок

**При любой проблеме первый шаг — всегда `lasso doctor`.** Он сам себя проверяет и говорит, что настроено не так.

| Симптом | Что делать |
|---|---|
| Не работает управление рабочим столом macOS | Отметьте `lasso-rust-helper` в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ / Запись экрана» (`lasso doctor` проведёт вас) |
| Не удаётся скрейпить залогиненную страницу | Один раз вручную залогиньтесь в локальном Chrome (пройдите и 2FA), затем скажите «открой мой залогиненный X» |
| Не работает сохранение в PDF | Скажите вместо этого «сделай скриншот всей страницы» |
| Поиск постоянно возвращает пустоту | Запустите `lasso doctor` и проверьте `machine_search_mcp` / `brave_keys`; проверьте, не истёк ли ключ Brave / не исчерпана ли квота; переиспользование машинного MCP + бесплатный фолбэк живого поиска работают без настройки |
| Ссылка не открывается | Скажите «эта ссылка мёртвая, найди архив» — проверим в Internet Archive |
| Пишет, что доступ к внутренней сети заблокирован | Перепроверьте URL; TUN-прокси-сети разрешены по умолчанию, для остальных внутренних сетей нужно явное разрешение |
| Хочу проверить анти-детект | Запустите `lasso doctor --stealth-check` — гоняет детекционную страницу creepjs и сравнивает с базовой линией (опционально, на повседневную работу не влияет) |

Полный FAQ и советы по отладке — в [`doc/TROUBLESHOOTING.md`](./doc/TROUBLESHOOTING.md).

## Кому подходит / Кому не подходит

**Подходит**

- **Активным пользователям Claude Code** — каждую неделю ищут, скрейпят и управляют рабочим столом и не хотят ставить отдельный MCP под каждый случай
- **Исследователям / авторам отчётов / дата-инженерам** — поиск, сбор чистого текста, оживление мёртвых ссылок от начала до конца
- **Тем, кто строит RAG / базы знаний** — веб-страницы в чистый markdown с маркерами цитирования, экономия токенов и денег
- **Специалистам по автоматизации / DevOps** — управление нативными приложениями macOS, скрейпинг залогиненных внутренних дашбордов
- **Всем, кто часто скрейпит залогиненные страницы** — переиспользование сессии локального Chrome, без повторного хранения учётных данных в конфиге

**Не подходит**

- **Тем, кто не использует Claude Code или другой MCP-клиент** — Lasso — это MCP-сервис и требует MCP-клиент, чтобы им управляли
- **Тем, кому нужна лишь одна возможность и уже есть под неё специализированное решение** — «всё в одном» может оказаться избыточным
- **Тем, кто хочет обходить 2FA / CAPTCHA** — красная линия; мы этого не делаем и не будем.
